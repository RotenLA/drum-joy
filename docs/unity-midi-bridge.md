# PD2U × 宿主（Unity）对接接口

网页作为 WebView 面板嵌入宿主。以下接口全部由网页在加载后挂载到 `window` 上，宿主调用即可；重复加载幂等。

## 1. 击打注入

```text
window.__pd2uNoteOn(note, velocity)   // note 1-127，velocity 1-127（0 视为静音，被忽略）
window.__pd2uNoteOff(note)            // 松开；长音符「全程按住」判定依赖它
```

可选第三个参数为宿主时间戳（毫秒，任意单调时钟，网页首次收到时自动与本地时钟对齐），低帧率下判定更准：

```text
window.__pd2uNoteOn(38, 100, hostTimeMs)
```

鼓棒姿态接口中的 `l` / `r` 已完整区分两根双色鼓棒。敲击发生时，网页会比较两根棒当时的真实 pitch / yaw 指向，选择更接近被敲鼓面的那一根执行上下层切换；宿主不需要在击打接口中重复传左右手。

默认 GM 鼓映射（映射屏可改，改后以用户配置为准）：

| note | 部件 |
| --- | --- |
| 36 | 右踏板（底鼓） |
| 38 | 军鼓 |
| 41 / 43 / 45 | 低通（地通） |
| 42 | 踩镲（合打） |
| 44 | 踩镲（脚踩，左踏板） |
| 46 | 踩镲（开打） |
| 47 | 中通 |
| 48 | 高通 |
| 49 | 吊镲 |
| 51 | 叮叮镲 |

踩镲三态：脚踩 → 44；手敲时看踏板状态，抬起 → 46，踩下 → 42。

注入事件与真实硬件（Web MIDI）走完全相同的映射、判定与鼓盘反馈。

## 2. 鼓棒姿态

```text
window.__pd2uSticks({ "v": 1, "l": { "p": 12.3, "y": -45.6 }, "r": null })
```

- `v`：协议版本，当前 `1`；
- `l` / `r`：左右鼓棒快照，`null` = 断连/无数据，网页隐藏该棒；
- `p`：pitch（度），棒头抬起为正，常规区间约 −20…+30；
- `y`：yaw（度），右手侧为正；
- roll 恒为 0，不需要传。

语义：网页只保留最新快照，在渲染帧里读取，不把调用次数当移动事件；超过 1 秒没有新调用即视为停流，鼓棒隐藏。原始角度直传即可，网页自己做相对校准，不要在宿主侧缓存绝对零点。

推送频率 ≤ 60 次/秒（源数据约 25Hz 即可）。

宿主侧守卫式调用示例：

```csharp
webView.EvaluateJavaScript(
  "window.__pd2uSticks ? window.__pd2uSticks({\"v\":1,\"l\":{\"p\":12.3,\"y\":-45.6},\"r\":null}) : 0");
```

## 3. 语言

语言由 URL 参数决定，网页读 `?lang=`，不识别的语言码回落英文：

```text
https://.../?lang=zh
```

支持：`zh`（= `zh-CN`）、`zh-TW`、`ja`、`fr`、`ko`、`de`、`it`、`es`、`en`（默认）。网页运行期不再提供语言切换按钮，宿主改语言时重新加载带新参数的 URL 即可。

## 4. 设备连接状态

```text
window.__pd2uDeviceState(snapshot)    // 宿主 → 页面：推全量快照（状态 UI 的数据源）
window.__pd2uGetDeviceState()         // 页面 → 宿主：同步查询，页面 mount 后必查一次
window.__pd2uDeviceEvent(event)       // 宿主 → 页面：播单条连接/断开事件，收到即提示
```

快照与事件：

```text
snapshot = { "v": 1, "m": true, "l": true, "r": false, "f": true }
event    = { "v": 1, "d": "m|l|r|f", "c": true }   // c: true 连接 / false 断开
```

- `m` 适配器、`l` 左棒、`r` 右棒、`f` 踏板；`m` 为 false 且其余全 false 视为适配器级断开；
- 事件零去重（宿主已过滤），网页收到即弹提示条（2 秒自动消失），文案由网页自行本地化（如「左鼓棒已连接」）；
- `__pd2uGetDeviceState()` 可返回对象或 JSON 字符串，两者都支持。

侧边栏会显示四个部件的状态小点；宿主未提供该接口时状态区不显示。

## 5. 退出

```text
window.__pd2uExit()    // 关闭面板回宿主大厅；无参、幂等、任意时机调用安全
```

网页侧的退出按钮只在检测到该接口已注入时才显示，且只调用它，不再直接调 `window.vuplex.postMessage` 等宿主内部通道。页面内三屏（游玩／谱面／映射／位置捕捉）导航由网页自理，不走此接口。

## 6. Chromium WebView 直连硬件（可选）

若 WebView 支持 Web MIDI，网页也可直接读硬件，无需宿主转发：CEF 需放行 `midi` 权限请求，Vuplex 需开启对应开关。放行后「映射」屏的设备下拉即可看到硬件。系统 WebView 无 Web MIDI 时设备下拉为空，属正常现象，走注入通道即可。

## 7. 调试与性能

- 游玩画面右下角「调试日志」浮层实时打印：硬件 MIDI、注入的 note-on/off、鼓棒快照（100ms 节流）、设备快照与事件、接口挂载，保留最近 200 条；
- 画质三档（自动／高／中／低）会按实测帧时间自动降档；WebView 请开启硬件加速，不要叠在半透明 Unity 层上，尺寸按实际显示像素设置；
- 游玩界面下方有「音符视觉偏移」「判定偏移」滑杆与「自动校准」（跟节拍器敲 8 下自动写入判定偏移）。
