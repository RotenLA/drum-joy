# 歌单详情圆角与歌曲卡尺寸调整

## 修改内容

1. **统一圆角**
   - 检查歌单首页卡、歌单内左侧歌曲条目、右侧歌曲详情大卡及其背景遮罩。
   - 所有外轮廓统一使用与首页歌单一致的圆角，不再出现尖角、局部直角或遮罩溢出圆角。
   - 保留当前统一斜率，圆角跟随倾斜后的完整轮廓。

2. **缩小歌单内歌曲详情卡**
   - 将右侧歌曲详情卡调整为与主界面歌单卡相同的宽高规格。
   - 在右侧可用区域内水平、垂直居中，不再铺得过大。
   - 卡内成绩、难度、音色、歌曲信息及下载/开始按钮按比例重新收紧，保持可读且不贴边。

3. **响应式检查**
   - 检查桌面 Preview 和手机横屏，确保圆角一致、歌曲卡居中、文字与按钮无裁切或重叠。
   - 保持现有透明度、Phigros 式左侧滑动、高亮第三首和点击归位逻辑不变。

4. **交付**
   - 验证构建和页面显示后，将本次新增/修改源码按原目录打包为可下载 ZIP，并附简短文件清单。
