# 律动大师：落点分区判定 + 触发难度修复

## 背景确认

- 网页正式版：MIDI 触发鼓面与踏板，角度只用于画面定位（教学、歌曲一致）——保持不变。
- 实验室·律动大师：屏蔽手部 7 个鼓面的 MIDI，鼓面全靠角度触发；仅 note36/note44（右/左踏板）继续走 MIDI——保持不变。

## 当前两个问题

1. **歌曲模式完全打不响**（教学能响）：两边代码接线相同，初步看接线无误，根因未确认——先加诊断再定位。
2. **手感不对、触发困难**：现在判定的是「挥棒起手时」指向的鼓面；从高处敲下来经过通鼓、最终停在军鼓，却可能不响或响错鼓。

## 改动方案

### 1. 落点判定（核心手感修复）— `src/taiko/gestureHit.ts`

- 挥棒过程记录整段下探轨迹，**触底/停住那一刻的俯仰+偏航角**送入分区表，落在哪个区就触发哪个鼓面（不再用起手姿态）。
- 例：高举过头下砸，途中经过高通/中通区域但不停留，最终停在军鼓区 → 只响军鼓。
- 触底瞬间的落点带 ±4° 俯仰滞回（沿用现有 PITCH_HYSTERESIS），避免停在上下层分界附近时抖动串层。

### 2. 触发难度放宽

- 下探最小幅度 10° → **7°**，触发角速度 240°/s → **200°/s**（保留「快速发力才算」的门槛，但不再苛刻）。
- 下探串帧窗口 130ms → **160ms**，覆盖一次真实挥击被 25~30Hz 姿态流切成 3~4 帧的情况。
- 防抖 120ms 不变。

### 3. 分区参数对齐开发端（按本次提供的新图）

- 俯仰分界 21° → **24.5°**。
- 上层偏航分界：−45.8° / −2.2° / +45.4°（现为 −38.5 / 4 / 52）。
- 下层偏航分界：−25.5° / +22.6°（现为 −26 / 23）。
- 同步更新 `src/taiko/stickMapping.ts` 的分区表与定位映射，画面棒尖位置与触发落点完全一致。

### 4. 歌曲模式不响的诊断与修复

- 在 `?debug=1` 下给角度判定加日志（每次下探起手/触底/触发及落点鼓面），便于真实设备复现时抓数据。
- 修复接线排查中发现的阻断点（例如进歌后订阅时机、姿态流与演奏状态的生命周期问题），确保歌曲与教学手感一致。

## 验证
