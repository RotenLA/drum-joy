# 游玩屏重做：扇形鼓盘下落式（无遮挡 3D 透视）

按用户草图（image-5：9 椭圆扇形排布 + 顶部消失点辐射车道）和选定的「3D 舞台渲染」概念方向实现。推翻 synthwave 场景与 Drum Hero 式统一判定线方案：**鼓盘本身就是音符落点**——9 个鼓盘扇形摊开、全部无遮挡可见，音符从顶部中央消失点沿各自的辐射车道滑向对应鼓盘，命中鼓盘发光弹跳。

## 一、场景构图（Canvas 单画布，伪 3D，不引 WebGL）

```text
┌────────────────────────────────────┐
│ 顶部：细进度条 / 得分(左) / 曲名+BPM(右) │
│         连击数（中上方悬浮，大号斜体）      │
│  ～～ 消失点（顶部中央，车道收束处） ～～   │
│    ╲ ╲ ╲ 辐射车道(9条细光线) ╱ ╱ ╱    │
│   🥁 扇形鼓盘阵（9 个椭圆，调色板描边）    │
│   （镲片在弧线两端偏高、鼓居中、踏板最近）  │
│   舞台地面（暗色 + 底部渐暗 vignette）    │
└────────────────────────────────────┘
```

- **背景**：深灰黑 `#0a0a0c` 舞台，顶部 20% 处聚光灯径向渐变，底部渐暗 vignette；不再使用封面铺底、无落日/山脉/网格
- **鼓盘阵**（扇形弧线，鼓手视角从左到右）：吊镲(最左偏高) → 踩镲 → 踩镲踏板(前下方) → 军鼓 → 底鼓(中央最前最大) → 高通 → 中通(前右下) → 地通 → 叮叮镲(最右偏高)。鼓盘画扁椭圆（顶部椭圆 + 侧面薄边营造厚度），本体深灰金属质感，调色板色只做描边 + 泛光，**鼓面不印任何字母**
- **车道**：9 条细白光线从顶部中央消失点辐射到各鼓盘中心，透明度低（约 0.2），远端淡出
- **音符**：带部件色发光的圆角芯片，从消失点由小变大沿车道滑向鼓盘，落到鼓盘即判定命中
- **命中反馈**：鼓盘瞬间增亮 + 放大回弹 + 火花粒子
- **HUD**：顶部细进度条（发光填充）、左上得分、右上曲名+BPM、连击数大号斜体浮在中上方

## 二、保持不变的部分

- 5分区 / 9分区全局设置、0.5x–2x 速度、键盘模拟击打、自动演奏、localStorage `taiko.settings.v1`
- 部件色板继续在 `laneLayouts.ts` 集中管理（9 色不变）
- 经典横向模式、谱面屏、映射屏不动；真实 MIDI 判定仍留到下一轮
- 5 分区模式下键盘闪光点亮该分区包含的全部鼓盘；音符仍按真实部件落到各自鼓盘（保持颜色学习机制）

## 技术说明

- 投影：消失点固定在顶部中央（归一化 0.5, ~0.12），音符深度 t∈[0,1]（0=消失点，1=鼓盘），屏幕位置 = 消失点与鼓盘锚点之间插值，尺寸随 t 放大
- 鼓盘锚点为归一化坐标常量，摆位/大小不满意只改 `laneLayouts.ts` 一张表
- 粒子与命中动画用 `performance.now()` 差值驱动；全部 Canvas 2D，Electron 零新依赖
