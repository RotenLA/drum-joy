# 修复横排模式倒计时、音符姿态与判定消失

## 调整内容

1. **彻底消除倒计时偶发卡死**
   - 倒计时改用页面单调时钟推进，不再依赖可能被手机或 Unity WebView 挂起的声音时钟。
   - 开始、继续和重开时仍主动唤醒声音，并把四条音轨排到同一个绝对起播点；倒计时结束后，以实际播放位置无缝接管谱面时间。
   - 增加一次性启动保护，避免声音唤醒重试产生重复倒计时、重复音轨或旧定时器干扰新一局。

2. **恢复下排音符的跑道透视角度**
   - 不再把原图作为水平矩形直接缩放，而是按每条跑道左右边线，将音符四角映射成随距离变化的透视梯形。
   - `Closed / Open / Foot` 始终绘制在色块内部，文字跟随色块透视、大小和中心位置变化，不再浮到边框外。
   - 保留原始素材的中间高亮与鼓件颜色，不增加白色外框。

3. **重做上排四种音符的姿态与落位**
   - 四张上排素材始终保持竖直，不再按飞行斜率旋转整张图片。
   - 以素材底部横片作为轨迹锚点，分别落在第 1、3、4、5 条跑道；菱形头保持在横片上方。
   - 横片沿对应跑道移动，素材整体随远近缩放，但不改变竖直朝向。

4. **同刻音符全程齐平**
   - 所有音符共享同一套“剩余时间 → 画面纵向位置”计算，不再按各自路径长度产生不同进度。
   - 同时刻的军鼓、底鼓、开闭镲，以及上排音符的底部横片，在出现、下落和抵达全过程保持同一画面高度。
   - 各音符的横向位置只由所属跑道决定，不影响纵向速度与齐平关系。

5. **补齐 Miss 与命中消失效果**
   - 未击中的音符到达判定点后短暂渐隐，不再瞬间删除或继续穿过判定点。
   - 命中后立即停止显示原音符，在落点绘制短促的高亮遮盖/爆闪，再快速消失。
   - 判定结果按单个音符记录，避免同一鼓件相邻音符被同一闪光错误遮盖；舞台模式原有效果保持不变。

## 验证与交付

- 连续多次测试首次开始、暂停继续和重新开始，确认倒计时不会停住、重叠或重复起播。
- 在 Unity 横屏尺寸检查五条下排透视、三种文字内嵌、四个上排素材竖直及第 1/3/4/5 跑道落位。
- 用同刻谱面逐帧检查上下排底部横片始终齐平，并检查不同速度档位仍为匀速。
- 分别验证 Perfect/Good 后遮盖消失、Miss 到点渐隐，以及连续同鼓件音符互不串扰。
- 检查编译与横屏运行错误，并将全部新增/修改源码打包为可下载 ZIP，附简短文件清单。

## 技术范围

- 主要修改横排渲染器、游玩时间轴和横排音符判定状态传递。
- 倒计时使用独立单调时间基准，歌曲播放仍由统一音频起播时刻控制。
- 横排音符改用统一纵向坐标；上排横片锚点对应底排槽位索引 `0 / 2 / 3 / 4`。
- 不修改谱面生成、MIDI 映射、判定窗口、舞台模式长音符或歌曲数据。
