# 偏移、Rolling in the Deep 谱面、分轨增益与缩圈提示

## 1. 更新默认偏移

- 音符视觉偏移默认改为 **0ms**。
- 判定偏移默认改为 **-35ms**。
- 升级偏移设置的存档版本，让已经运行过旧版本的设备也采用这组新初始值；用户之后仍可手动调整和自动校准。
- 同步更新谱面页问号说明中的默认值。
- 教学继续读取同一套全局偏移，因此自动应用 0ms / -35ms。

## 2. 检查并修正 Rolling in the Deep 谱面过空

- 对这首预设曲的原始 MIDI、量化后鼓点、各鼓件数量和四档最终音符数量逐层对比，确认音符在哪一层被大量丢弃。
- 针对确认的问题修正规则；优先做通用修复，只有当这首 MIDI 的结构确实特殊时才增加按曲目识别的兼容处理。
- 保留既定约束：轻松/入门/标准/困难的鼓件范围、踩镲互斥规则、同刻最多两个手部件、左踏板长音符逻辑不变。
- 升级谱面缓存版本，避免设备继续读取旧的稀疏谱面；谱面页和游玩页继续共用同一份结果。

## 3. 四条分轨统一增加 3dB

- Vocals、Drums、Bass、Other 在现有滑杆音量基础上统一乘以 `10^(3/20)`（约 1.4125）。
- 滑杆仍显示 0%–100%，四轨比例和实时调节方式不变；Drums 为 0% 时仍保持静音。
- 试听和正式游玩都经过同一播放器，因此两处音量一致。

## 4. 教学与游玩加入轻量缩圈判定提示

- 在共享舞台绘制中，为即将到达的音符找到对应鼓件，并在鼓面外侧绘制同形外框：圆鼓使用椭圆，左右踏板使用与踏板一致的斜方形。
- 外框从略大尺寸平滑缩到鼓面边缘，到达时淡出；颜色沿用对应鼓件，但低透明度、细描边、弱或无泛光，避免抢过音符本身。
- 同一时刻需要敲多个部件时，各部件同时显示缩圈；长音符只提示开始踩下的时刻。
- 缩圈只在音符进入临近判定区域后出现，不会从车道起点一路常亮。
- 教学和正式游玩都调用同一舞台绘制，因此视觉和时机保持一致；低画质档保留提示，但关闭额外泛光以控制安卓性能。
