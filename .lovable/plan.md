# 新手教程 + 参数归位

## 一、参数搬到「谱面」页（全局设置）

从游玩页移出、放进谱面页顶部的「全局设置」区（一次设置，所有歌曲通用）：

- 画质（自动 / 高 / 中 / 低）
- 音符视觉偏移、判定偏移（默认 +80ms）
- 自动校准按钮
- 鼓音色 开/关
- 下落速度（原游玩页的速度滑杆）

难度本来就在谱面页，保持在那里；游玩页里的难度按钮删掉。游玩页只留：开始/暂停、进度、判定与连击、调音台。

同时删除 ASDFJ 键盘敲鼓（只靠适配器 MIDI 演奏），空格开始/暂停保留。

## 二、问号说明

谱面、游玩、映射三页的每个参数标题旁加一个圆形「?」，点击弹出一段中文说明（例：判定偏移＝把设备与音频的延迟补回来，敲得早就调大）。用一个统一的小组件实现。

## 三、开场教程流程

首次打开（以及以后可从侧栏「教程」重进）先显示欢迎页：「跳过」→ 直接进正式界面并停在**谱面**页；「开始教学」→ 进入教学。是否看过存本地。

教学步骤：

1. **连接适配器**：提示打开 PD2ULTRA / PD2MAX 适配器并用 USB 连电脑。检测到名称里含 pd2u / pd2max / pd2 / max（忽略大小写）的 MIDI 设备即算成功，显示成功提示后自动进下一步。
2. **连接鼓槌与踏板**：提示打开鼓槌和踏板，随意敲几下、踩几下。收到 note 36 或 42 → 踏板成功；收到其它已映射音符 → 鼓槌成功。两项都亮后成功提示并自动进下一步。
3. **认识部件**：只展示五个部件（左右踏板、开闭镲、军鼓、低通）并逐个点亮介绍。
4. **短音符**：动画演示短音符下落到鼓面该怎么敲 → 用户点「明白了」或「再看一次」。
   - 练习军鼓：4/4、100BPM 节拍器，先空四拍预热，然后持续出音符，连续命中 8 下算过 → 鼓励页（「下一步」/「再练一次」）。
   - 同样流程练习底鼓（右踏板）。
5. **长音符**：动画演示长音符样式与「踩住不放」→ 确认 → 练习左踏板踩住 8 拍。
6. **组合练习**（每个都是动画教学 + 连续成功 8 次 + 鼓励页）：
   - 开闭镲 + 军鼓
   - 左踏板踩住 + 8 下闭镲
   - 军鼓 + 底鼓
7. **完成页**：点「开始游玩」进入正式界面（落在谱面页）。

每一步顶部都标明当前教学名称与进度（例：4/7 短音符）。练习中可「跳过本节」。

## 四、需要你确认的两点

1. 第 4 步你写的是 note36 或 note42 算踏板：本项目里 36 是底鼓（右踏板），42 是踩镲（手打闭镲音）；44 才是踩镲踏板。是否改成「36 或 44 算踏板」？如坚持按 36/42 我就照原文实现。
2. 教学练习使用内置合成鼓音色发声（不下载采样），可以吗？

## 五、技术说明

- 新增 `src/taiko/tutorial/`：`TutorialOverlay.tsx`（步骤机 + 全屏遮罩）、`steps.ts`（步骤定义与通过条件）、`TutorialPad.tsx`（复用 stageRenderer 的鼓盘/音符绘制做小舞台演示与练习）。
- 新增 `src/taiko/settingsStore.ts`：把画质、视觉/判定偏移、鼓音色、速度收成一处全局设置（沿用现有 localStorage 键，速度从 `taiko.settings.v5` 读）。
- 新增 `src/components/HelpDot.tsx` + `src/taiko/helpTexts.ts`：问号气泡与文案表。
- `TaikoShell.tsx`：初始页改 `chart`；挂载教程遮罩；新增教程重入入口；教程完成标记 `taiko.tutorial.v1`。
- `midiInput.ts`：暴露设备名列表变化订阅供教程第 1 步轮询判定（已有 `onState`/`inputs()` 可直接用）。
- `FallScreen.tsx`：移除画质/偏移/校准/鼓音色/难度/速度 UI 与 `KEY_BY_PART` 键盘监听；`ChartScreen.tsx` 接收这些控件。
- 练习判定复用 `metronome.ts` 时钟 + `midiManager.onNote/onNoteOff`，长音符按住时长以节拍数判定。
