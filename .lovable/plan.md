# 歌单与歌曲卡片视觉调整

## 调整内容

1. **右侧歌曲卡片恢复旧版布局**
   - 保留现在歌单内左侧倾斜列表、固定第三位高亮和右侧大方框的整体结构。
   - 将右侧红框内的歌曲信息改回参考图 2 的比例与排布：成绩居上、四档难度横排居中，歌曲名称与时长/BPM/拍号位于左下，手机音色与鼓组选项居中偏下，下载/开始位于右下。
   - 排行榜与收藏保留在卡片右上角；长歌名继续自动滚动。
   - 右侧内容充分利用大方框，不再缩成现在中间的一小块，同时保持统一斜率和反向校正，文字不会变斜。

2. **歌曲卡片使用所属歌单颜色**
   - 当前打开哪个歌单，右侧歌曲大方框就使用该歌单的底色；收藏、历史与各自定义标签沿用首页对应颜色。
   - 不读取或恢复已废弃的歌单背景图片。

3. **统一半透明层次**
   - 首页歌单卡片底色降低不透明度，透出后方模糊游玩画面。
   - 右侧歌曲大方框的歌单色也使用相同透明度，视觉浓度与当前左侧未选中歌曲条一致。
   - 选中歌曲的浅色高亮保持足够清晰，不因透明化降低辨识度。

4. **验证与交付**
   - 检查桌面与手机横屏：右侧内容不裁切、不溢出，按钮尺寸统一，左右区域保持现有比例。
   - 验证点击、滑动切歌后卡片颜色与内容同步更新。
   - 将全部新增/修改源码按原目录打包为新版 ZIP，并附简短文件清单。

## 技术说明

- 在现有歌单颜色表上增加统一的半透明表现，不新增背景图片或新数据字段。
- 复用现有 `CardControls`、排行榜、收藏、下载与开始逻辑，仅调整展示层级和尺寸。
- 颜色与透明度集中为语义样式，避免各卡片分别写不一致的视觉值。
