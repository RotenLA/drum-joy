# 四档难度重排 + 五首预设曲 + 单一玩法

## 难度（新增「轻松」，共四档）

| 难度 | 鼓面显示 | 出现的音符 |
| --- | --- | --- |
| 轻松 | 军鼓、左右踏板、踩镲、低通 | 军鼓、踩镲、左踏板（整曲踩住） |
| 入门 | 同上 | 军鼓、踩镲、左踏板（整曲踩住）、右踏板 |
| 标准 | 再加吊镲、叮叮镲 | 军鼓、踩镲、左踏板（踩住，偶尔松开）、右踏板，低通/吊镲/叮叮镲可能出现 |
| 困难 | 再加高通、中通 | 同标准，另外高通、中通低概率出现 |

共同规则：
- 允许同时打击（手部件同刻最多两个的限制保留）。
- 踩镲与低通/吊镲/叮叮镲不允许同一时刻出现（同刻时按难度优先级取一个）。
- 左踏板恢复长音符：整曲一条，从第一个闭镲踩下延伸到结束；标准/困难在开镲处断开，开镲后重新踩下。
- 轻松/入门不出现开镲，全部按闭镲处理。
- 谱面仍按文件名 + 难度固化缓存，同一首歌每次进入完全一致。

## 谱面屏：五首预设曲

- 删除拖拽/选择文件导入，改为五首预设歌曲列表：Rolling in the Deep、红色高跟鞋、李白、As Long As You Love Me、Creepin' Up On You。
- 点一首歌开始加载，只显示一个百分比进度条（不显示文件名或阶段），完成后提示「已就绪」。
- 加载完成后保留现有的速度/拍号信息、偏移微调、播放试听、节拍器与谱面统计预览。
- 四轨调音台照旧（Vocals/Bass/Other 100%，Drums 0）。

## 游玩屏

- 只保留「舞台下落」，删除节奏跑道与生存模式（含其入口与渲染代码）。
- 默认速度 1.5x，默认难度轻松（旧存档里的模式/速度设置迁移到新默认）。
- 舞台背景换成干净的暗夜网格：深灰底 + 极淡地平线网格 + 中心微弱聚光，不再铺专辑封面。

## 技术说明

- `laneLayouts.ts`：`LayoutMode` 增加与四档对应的可见部件集（five / seven / nine 复用，轻松与入门共用 five）。
- `difficulty.ts`：`Difficulty` 增加 `"easy"`；按上表重写各档的部件白名单与出现概率；新增「踩镲 vs 低通/吊镲/叮叮镲 同刻互斥」过滤；恢复 `pedalHolds` 调用并改为整曲单条长音符（标准/困难按开镲切分）。
- `chartCache.ts`：缓存键升到 `taiko.charts.v5`。
- 新增 `src/taiko/presetSongs.ts`：五首曲目的 CDN 资源指针 + 带字节进度的加载函数（各 stem 的 mp3 与 mid 上传为 Lovable 资源）；`sampleSong.ts` 并入或删除。
- `ChartScreen.tsx`：移除导入 UI 与拖放逻辑，改为预设列表 + 百分比进度。
- `FallScreen.tsx` / `TaikoShell.tsx`：删除模式切换与 `runwayRenderer.ts`、`survival.ts`，设置默认 `speed: 1.5`、`difficulty: "easy"`。
- `stageRenderer.ts`：`drawBackground` 改为网格背景（保留离屏缓存与画质档位开关）。
