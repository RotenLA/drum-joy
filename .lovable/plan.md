# 安卓旧 WebView 向下兼容与新手教学恢复

## 目标

- 尽量让 Android 11 等旧设备正常显示和游玩，不单凭 Android 系统版本拦截。
- 对确实缺少必要能力的内置浏览器，在应用内容加载前显示清晰的升级弹窗，避免白屏。
- 恢复新手教学：左侧为教学舞台，右侧为说明；右上角独立“离开教学”。
- 首次使用自动进入教学；离开或完成后，可从选歌顶部重新进入。

## 1. 安卓兼容继续下探

### 启动前兼容检查

- 在主界面加载前运行一段旧浏览器也能解析的轻量检查，识别 Android WebView/Chrome 内核版本与必需能力。
- 不按“Android 11”直接判死刑：Android 系统版本和 WebView 内核版本分开判断。
- Chrome/WebView 90 作为正式支持基线；版本号取不到时改用能力检测，不直接误拦。
- 缺少 Canvas、音频时钟、基础脚本能力等无法补救的设备，显示全屏升级弹窗，不再继续启动游戏。
- 弹窗按 URL 的 `?lang=` 显示对应语言；核心提示为“系统浏览器组件版本过低，请升级 Android System WebView / Chrome 或系统后重试”。
- 保留页面左上角“退出”，升级弹窗也提供退出入口，并仍只调用 `window.__pd2uExit()`。

### 可补救能力降级

- JS 构建目标与现有 CSS 降级目标统一到 Chrome 90，避免样式能显示但脚本无法执行。
- 继续清理旧 WebView 不稳定的现代 CSS，用十六进制 / RGBA 与普通布局作为兜底；模糊等增强效果不支持时允许降级为实色玻璃层。
- `ResizeObserver` 不可用时回退到窗口尺寸变化监听，保证舞台仍能正确铺满。
- Wake Lock、延迟信息、存储等非核心接口继续做能力检测；不可用时只关闭对应增强，不让整页失败。
- 在 Android 11 / Chrome 90 模拟环境及当前 Android 环境分别验证启动、选歌、设置、加载歌曲和演奏。

## 2. 恢复新手教学

### 进入与退出

- 使用新的教学记录键：第一次进入应用自动打开教学；完成或主动离开后不再自动出现。
- 选歌页顶部右侧控制区新增一个小型“教学”图标按钮，放在“选择歌曲 / 历史演奏”左侧。
- 页面左上角“退出”始终只负责退出整个网页；教学右上角“离开教学”只返回选歌页，两者职责完全分开。
- 完成最后一课后标记为已完成并返回选歌页；手动再次进入不会清除歌曲、难度、速度或全局设置。

### 横屏教学布局

```text
┌──────────────────────────────┬──────────────────┐
│                              │  课程标题 / 进度  │
│       教学舞台与鼓组          │                  │
│       音符演示与实时练习       │  当前操作说明      │
│                              │  检测状态 / 提示   │
│                              │  上一步 / 下一步   │
└──────────────────────────────┴──────────────────┘
                                      右上：离开教学
```

- 左侧约 68%：始终保留鼓组舞台，演示、练习、命中反馈都在同一舞台内完成，不整页跳动。
- 右侧约 32%：固定说明栏，显示课程名称、进度、当前要求、设备检测状态和操作按钮。
- 手机横屏高度不足时，只允许右侧说明栏独立上下滑动；左侧舞台保持固定比例。
- 窄屏兜底为上下结构，优先保证舞台和“离开教学”按钮可见。

### 教学内容

恢复此前确定的课程逻辑，并调整为左舞台、右说明：

1. 连接 PD2U / PD2MAX 适配器。
2. 连接鼓槌与踏板；note 36 或 44 识别为踏板，其余已映射音符识别为鼓槌。
3. 认识鼓件与对应位置。
4. 军鼓短音符：4 拍预热后边演示边练习，连续正确 8 次通过。
5. 底鼓短音符：同样连续正确 8 次通过。
6. 左踏板长音符：踩住完成长音符练习。
7. 组合练习：开闭镲 + 军鼓、左踏板 + 闭镲、军鼓 + 底鼓。
8. 完成页：返回选歌。

- 练习继续使用现有 MIDI 输入、节拍器和内置鼓音色；演示音符到点会亮起，但不会替玩家完成判定。
- 每节通过后在左侧舞台上显示完成提示，右侧提供“下一步 / 再练一次 / 跳过本节”。
- 教学中不加载歌曲，也不写入历史演奏记录。

## 3. 多语言与兼容性

- 新增教学、设备检测、升级提示所需的简中、繁中、英、日、韩、法、德、意、西文案；缺失时按现有规则回落英文。
- 教学首次完成状态仅保存在本机，不改变当前 URL 语言规则。
- 所有教学按钮保持现有深色玻璃与橙色选中体系，旧 WebView 下仍有纯色兜底。

## 技术范围

- 安卓能力检测与启动拦截：`src/taiko/platform.ts`、`src/routes/__root.tsx`、`src/routes/index.tsx`、`vite.config.ts`、`src/styles.css`。
- 新建教学模块：`src/taiko/tutorial/` 下的步骤定义、舞台和分栏界面。
- 接入入口与状态：`src/taiko/FallScreen.tsx`、`src/taiko/SongPicker.tsx`。
- 多语言：`src/taiko/i18n.tsx` 与各语言字典。
- 不改变正式歌曲谱面、判定窗口、鼓棒角度分区、云端曲库和历史演奏规则。

## 验证与交付

- 验证首次自动进入、离开后回选歌、完成后回选歌、顶部按钮可重复进入。
- 验证教学 MIDI 检测、短音符、长音符、组合练习及中途离开均正常。
- 验证页面左上退出与教学右上离开互不冲突。
- 模拟 Chrome/WebView 90、低于基线和版本未知三类环境：可支持设备进入应用，不可支持设备只显示升级弹窗。
- 桌面与手机横屏检查教学左右分栏、右栏滚动和文字不溢出。
- 将所有新增/修改源码按原目录结构打包 ZIP 放到 `/mnt/documents/`，附简短文件清单与本地三步命令说明。
