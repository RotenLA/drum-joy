# 正式界面整体改版：全屏舞台、隐藏导航、18:9 与位置捕捉

## 目标

- 删除新手教学及其入口，打开后直接进入正式界面。
- 舞台游玩画面始终作为全屏背景；谱面和映射改成覆盖在舞台上的窗口。
- 左侧导航默认隐藏，通过左上角菜单按钮展开，再次点击菜单按钮或遮罩关闭。
- 舞台逻辑比例由 16:9 改为 **18:9（2:1）**，适配大部分横屏手机。
- 两根鼓棒的可视长度和粗细整体缩小约一半。
- 新增「位置捕捉」，逐一采集七个手击鼓面的左右鼓棒角度，并导出一份可发送的校准 JSON 文件。

## 1. 正式界面重构

- 移除教学的启动状态、覆盖层和侧栏入口；教学目录保留还是删除将以“无其他引用”为准，确认无引用后删除，避免无用代码继续打包。
- `FallScreen` 常驻最底层并铺满可用窗口，不再随页面切换卸载。
- 左上角放置紧凑的菜单图标；展开后显示游玩、谱面、映射、位置捕捉四项。
- 点「游玩」或关闭按钮时收起侧栏，露出完整舞台。
- 谱面、映射使用舞台上方的可滚动覆盖窗口；窗口带明确关闭按钮，关闭后回到纯舞台。
- 覆盖窗口打开时暂停游玩，避免后台继续计分、播歌和消耗绘制性能；关闭后不自动续播，由用户主动继续。
- 顶部歌曲信息与全屏操作并入抽屉/覆盖窗口，避免长期占用舞台高度。

## 2. 18:9 横屏舞台

- 舞台坐标系统统一改为 2:1；鼓盘、车道、音符、HUD、鼓棒和点击命中共用同一个 18:9 逻辑区域。
- 背景继续裁切铺满真实屏幕；不同手机比例产生的少量边缘区域只多显示背景，不拉伸鼓阵。
- 移除当前游玩框的 70vh / 720px 限制，让舞台真正占满正式界面。
- 同步调整映射静态鼓阵和位置捕捉画面，确保三处看到的鼓面坐标一致。

## 3. 鼓棒缩小

- 棒身长度、根部/尖端粗细、棒头和落点圈统一缩小约 50%，角度输入与落点计算暂不改变。
- 左右棒仍保留不同颜色，继续画在鼓面和音符上层。

## 4. 「位置捕捉」流程

位置捕捉只处理七个手击鼓面，不包含两个踏板：

1. 进入后先检查两根鼓棒姿态数据与 MIDI 输入；缺少任一项时明确提示，不允许开始采集。
2. 展示全部七个鼓面，但一次只高亮一个目标；顺序为：吊镲 → 高通 → 中通 → 叮叮镲 → 踩镲 → 军鼓 → 地通。
3. 每个鼓面先采左棒 3 次，再采右棒 3 次；屏幕显示当前目标、当前手、进度 `1/3`。
4. 用户按提示敲目标鼓面；收到该鼓面的 MIDI 音符时，同时抓取对应手当前的 `pitch/yaw` 快照。错误鼓面不计数并提示重试。
5. 每组三次去除明显异常值后取中位数；当前目标完成后自动进入下一手或下一鼓面。
6. 全部 42 次采样完成后显示总览：每个鼓面左右棒的角度、采样离散度和异常项；离散过大的鼓面标记为需要重测。
7. 支持重测单个鼓面/单只手，不必整套重来。
8. 确认后保存到本机，并提供「导出校准文件」；同时提供「导入校准文件」和「恢复默认」。

## 5. 校准文件与运行时应用

导出 JSON 包含：

- 文件版本、生成时间、画面比例和鼓阵布局版本。
- 七个鼓面的目标锚点快照。
- 左右棒各自每次采样的原始 `pitch/yaw`、三次中位数、离散度与被剔除项。
- 左右棒分别拟合出的角度到舞台坐标换算参数，以及拟合误差。

运行时：

- 分别为左棒、右棒拟合二维仿射映射，不再只依赖目前写死的 ±45° 线性范围。
- 鼓棒尖端绘制使用校准后的坐标，因此会更贴近真实鼓面。
- 校准文件保留全部原始数据；你把 JSON 发给我后，我可以检查每个鼓面的真实角度分布，再决定是否需要升级为分段或非线性换算，无需重新采集。
- 本轮不改变游戏的 MIDI 判定来源：MIDI 仍负责确认敲中了哪个鼓件，位置捕捉先解决鼓棒视觉落点匹配。仅凭当前 pitch/yaw 数据无法可靠识别“何时击打”，所以不把姿态单独作为判定器。
