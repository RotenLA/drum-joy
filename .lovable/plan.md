# 横排角度、音符与歌曲卡片一次性修正

## 目标
- 按舞台下落的轴定义纠正横排模式：左右角负责选列，上下角负责棒尖动作与角度敲击。
- 横排所有普通音符固定同一宽度、高度与描边，不再因重击标记或鼓件变化忽宽忽窄。
- 暂停菜单三项完全同级、同色、同边框；歌曲卡片的信息位置与未加载歌名字号同步优化。

## 1. 横排角度轴纠正
- 以舞台模式现有定义为准：宿主 `y / YAW` 是左右偏航，负责横向选择鼓件；`p / Height` 是上下俯仰，负责棒尖轻微上下动作和下挥触发。
- 横排画面改为用 `y` 选择当前可见列，用 `p` 驱动棒尖上下位移，并沿用舞台模式的俯仰有效范围与钳制。
- 实验室角度击打改为从 `p` 识别下挥、速度、行程和触底；触底帧再用 `y` 确定最终列。挥击途中经过的列不触发，左右棒仍独立，两个踏板仍只走 MIDI。
- 将横排列映射函数及注释统一改成偏航语义，避免后续再次把 Height 与 YAW 接反。

## 2. 横排音符尺寸彻底统一
- 删除横排普通音符对 `big` 重击标记的 1.22 倍放大；所有鼓件、所有时刻使用同一个列宽基准。
- 固定普通音符的宽高比例、填充透明度、描边粗细和发光范围，军鼓及其他鼓件不再一会儿宽、一会儿窄。
- 长音符主体宽度与普通音符统一，不再额外收窄；保持已确定的直角边和多层流光。
- 检查 5 / 7 / 9 件难度下的自适应：同一难度内音符尺寸一致，切换难度时仅随可用总宽度整体缩放。

## 3. 暂停菜单视觉统一
- “继续 / 重新开始 / 退出”使用完全相同的默认文字色、边框色、背景、宽高、字号与内边距。
- 移除“继续”当前更亮的文字和更强外框；仅保留三项一致的悬停反馈，不默认突出任何一项。
- 检查中文及其他语言长文案，确保三个按钮外框不被文字撑成不同尺寸。

## 4. 歌曲卡片位置与字号
- 加载完成后，将分数、难度、手机音色与鼓组作为一个整体略微上移。
- 以上移量对准“难度按钮组的中心”与卡片纵向中心，而不是让整个信息组的外框居中；分数位于其上，手机音色与鼓组位于其下。
- 未加载歌曲的竖排歌名增大字号，同时保留现有倾斜方向、溢出检测和长歌名滚动，避免窄卡片裁切。
- 桌面和手机横屏分别检查展开/未展开状态，确保歌名、设置区和开始按钮不重叠。

## 验证与交付
- 用模拟姿态分别验证：只改变 `y` 时横向逐列移动；只改变 `p` 时仅上下动作并可完成击打；最终落点列正确且不锁死。
- 用同时包含普通、重击、军鼓及长音符的谱面逐帧检查尺寸，确认宽高和描边稳定。
- 实测暂停菜单、歌曲加载前后卡片在桌面与手机横屏的布局。
- 完成类型检查、自动构建与页面运行检查后，按原目录结构打包全部新增/修改源码 ZIP，并附 `FILES.txt`。
