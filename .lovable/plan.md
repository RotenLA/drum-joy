# 四个小修

## 1. 踩镲长音符中途消失 + 角度不对

原因：飞行音符只在「当前时间前 4 秒」的时间窗内绘制，而踩镲长音符长达整首歌，开始超过 4 秒后就被时间窗丢掉了。

- 长音符单独收集成一份小列表（整首歌通常只有一条），不受时间窗限制，只要还没结束就一直绘制；短音符继续沿用现在的时间窗与游标优化，性能不受影响。
- 长音符的色带改成跟踏板同一套朝向：现在色带是按车道方向取垂直边算宽度，和踏板本身的倾斜 + 压扁不一致，所以看起来「歪」。改为在踏板的倾斜/压扁坐标系里生成带宽方向，头尾宽度仍按透视缩放，视觉上就是一条随纵深收窄、与踏板顶面同角度的带子。

## 2. 自动校准：响到打完为止，可手动停止

- 节拍器不再只响 8 下：进入校准后持续按 120BPM 响，直到收满 8 次敲击自动结束并写入判定偏移。
- 校准中按钮变为「停止校准」，点击立即停止节拍器；已收满 3 下以上就照样算出偏移，不足则放弃不改动数值。

## 3. 未开始时不显示音符

给渲染帧加一个「显示音符」开关：`idle` 阶段不画飞行音符（鼓盘、背景、HUD 照常），倒计时开始起才出现音符。

## 4. 内置鼓音色

新增一个用网页音频合成的鼓音色（不额外下载文件，安卓中低端机也不吃内存）：

- 底鼓：正弦音高下滑 + 短促点击层；军鼓：噪声 + 带通 + 一层音体；踩镲开/闭、吊镲、叮叮镲：高通噪声，闭镲极短、开镲与镲片带较长衰减；高/中/低通：不同基频的音高下滑。
- 每次命中（含 MIDI 注入与键盘）按力度触发对应音色，走独立总音量节点，避免和 stem 播放互相影响。
- 演奏界面加「鼓音色」开关，默认开启，状态与其他设置一起记住。

## 技术细节

- `src/taiko/stageRenderer.ts`：`noteItems` 拆分长音符列表 + 长音符色带改用踏板坐标系；`StageFrame` 增加 `showNotes`。
- `src/taiko/FallScreen.tsx`：帧数据传 `showNotes: phase !== "idle"`；校准改为循环节拍器 + 停止按钮；命中处调用鼓音色；新增开关 UI。
- 新增 `src/taiko/drumKit.ts`：合成音色，复用 `metronome.ts` 的共享 AudioContext。
- `src/taiko/TaikoShell.tsx`：设置键升到 `taiko.settings.v6`，新增 `drumKit: true`。
