# 鼓件识别修正 + 基础节奏型库 + 复杂节奏简化

## 一、识别修正：镲被认成军鼓、军鼓没被认出

现在是三个独立滤波器各自做 onset 检测：军鼓带 1200–5000 Hz、踩镲带 6000 Hz 以上。镲片主要能量恰好落在 2–8 kHz，所以**每次镲都会在“军鼓带”触发一次 onset**，被写成军鼓；而真实军鼓的辨识特征是「150–250 Hz 鼓腔共振 + 2–5 kHz 短促噪声、衰减快」，只看 1200–5000 Hz 无法与镲区分，镲密集处军鼓反被吞掉。

### 新方案：先找 onset，再逐击点分类

1. 全频带（宽带 + 高频加权）做一次统一 onset 检测，得到全曲击点，避免同一击点被三条链路各算一次。
2. 每个击点取短窗（前 60 ms / 后 180 ms），算特征：低频能量（30–120 Hz）、鼓腔能量（150–300 Hz）、中高噪声（2–6 kHz）、极高能量（8 kHz+）、衰减时长（掉到峰值 25%）、谱心。
3. 分类顺序：
   - 低频主导且极高能量弱 → 底鼓
   - 有鼓腔能量 + 中高噪声、衰减短（< ~120 ms）→ 军鼓
   - 无鼓腔能量、极高能量强、衰减长 → 镲
   - 同一时刻允许同时判定底鼓与手击件（底鼓+镲同拍很常见）
4. 阈值按整曲分位数自适应，不用固定数值。
5. 用 Mixdown-ACE.mp3 验证：军鼓应落在 2、4 拍附近，镲成为细分层，两者不再混淆。

## 二、基础节奏型库（游玩谱面的真正来源）

自动分析结果只用于「理解这首歌的感觉」，实际游玩谱面改由内置的**基础节奏型库**驱动，保证好打、规整。

### 节奏型库

内置一组标准鼓型（每型含 1 小节骨架 + 若干变体/过门），例如：

- 八分摇滚（kick 1/3，snare 2/4，hat 8 分）
- 十六分摇滚（hat 16 分）
- 四踩 / 四分底鼓（Disco、Four-on-the-floor）
- 半拍 Half-time（snare 落 3 拍）
- Shuffle / 三连感
- Ballad 慢速简约（kick 1，snare 3，hat 4 分）
- Funk 切分（16 分 kick 切分 + ghost snare）
- 6/8 复合拍型

每型带元数据：适用拍号、BPM 区间、底鼓密度、军鼓位置集合、镲细分等级、强度等级。

### 匹配：用户选的段落 → 最相似的基础节奏型

把用户选中的主体段落转成同一套特征（底鼓位置位图、军鼓位置位图、镲细分级别、BPM、拍号），与库中每型算加权距离（军鼓位置权重最高，其次底鼓，镲细分最低），取最接近者作为主型；谱面屏显示匹配结果并允许**手动改选**其他基础型。

### 编谱：基础型为主，偶尔变体

- 在有效鼓段区间逐小节铺主型骨架。
- 变体由确定性哈希 + 小节活跃度决定：乐句末（每 4 小节）偶尔过门、能量上升处加吊镲、高能段加通鼓，频率优先级仍为：底鼓/开闭镲/军鼓 > 吊镲/高通/中通 > 叮叮镲/低通/踩镲。

### 无鼓/弱鼓段落自动降级

按小节活跃度分四档，同一主型逐级简化：

| 活跃度 | 处理 |
| --- | --- |
| 0（几乎无声） | 留空 |
| 很低 | 只有镲（4 分）或只有底鼓（每小节 1 下），按频谱重心哪一侧更强来决定 |
| 中 | 主型骨架，去掉细分与装饰 |
| 高 | 完整主型 + 变体/过门 |

## 三、复杂节奏简化（密度档位）

谱面屏加三选项：轻松 / 标准 / 原样（默认标准）。作用于编谱后的结果：

1. 保留强拍与反拍骨架（底鼓 1/3 拍、军鼓 2/4 拍）。
2. 镲 16 分降 8 分；轻松档再降 4 分。
3. 同时刻（< 40 ms）多件同响，只留优先级最高一件。
4. 每小节音符上限：轻松 6 / 标准 10 / 原样不限；超限时先删离强拍最远的。
5. 最小相邻间隔：轻松 160 ms / 标准 110 ms。
6. 5 分区维持现有鼓件白名单；9 分区装饰量随档位缩减。
7. 全程确定性：同歌 + 同主型 + 同档位 + 同分区结果一致。

## 技术调整

- `src/taiko/drumAnalyze.ts`：改为统一 onset 检测 + 逐击点特征分类，`DrumAnalysis`（segments / barActivity / activeRange）输出结构不变。
- 新增 `src/taiko/groovePatterns.ts`：基础节奏型库定义 + 特征。
- 新增 `src/taiko/grooveMatch.ts`：段落 → 基础型匹配打分。
- 新增 `src/taiko/arrange.ts`：以基础型为骨架的全曲编谱（含活跃度降级与变体），`buildChart` 迁到此处。
- 新增 `src/taiko/chartSimplify.ts`：密度档位与简化函数。
- `src/taiko/songStore.tsx`：增加 `grooveId`（匹配/手选的基础型）与 `density`，写入 `taiko.settings.v2`。
- `src/taiko/ChartScreen.tsx`：显示匹配到的基础型、允许改选、密度档位控件，改动即时重算预览。
- `src/taiko/FallScreen.tsx`：编谱依赖加入 `grooveId` 与 `density`。

## 验证

1. 导入 Mixdown-ACE.mp3：军鼓行有音符、镲不再顶替军鼓。
2. 选中段落后显示匹配的基础节奏型，手动改选后谱面随之变化。
3. 前奏/间奏等弱鼓段只出现镲或底鼓，不留大片密集音符。
4. 三档密度分别检查每小节音符数与最小间隔。
5. 5 / 9 分区切换核心节奏一致、装饰量随档位变化。
6. 构建通过，改动源码按目录结构打包到 `/mnt/documents/taiko-groove-library.zip`。
