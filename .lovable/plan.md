# 固定显示侧栏退出按钮

## 修改内容
- 删除侧栏顶部的“未选择歌曲 / No song selected”文字，不再用歌曲状态占据该位置。
- “退出 / Exit”按钮始终显示，不再取决于 Unity 接口是否已完成注入。
- 点击按钮时只调用约定接口 `window.__pd2uExit()`；若接口尚未注入，则保留调试日志，不调用其他 Unity/WebView 通道。
- 保留现有九语言规则，按钮文字继续跟随 URL 的 `?lang=`。

## 验证
- 普通浏览器与 Unity 接口未注入时，侧栏顶部都能看到退出按钮。
- 模拟延迟注入接口后，点击只触发一次退出调用。
- 加载或未加载歌曲都不再显示“未选择歌曲”。
