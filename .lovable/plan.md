# 谱面屏改版：正拍镲、歌曲段落分析、自定义节奏、谱面难度 + 倾向风格

## 1. 镲落在正拍（编谱修正）

现在镲的细分降级是「先铺满 16 分，再按网格筛」，筛的时候容易只剩反拍，听感与手感都别扭。改为直接按目标细分生成：

- 轻松：镲只在每拍正拍（四分），绝不出现反拍。
- 标准：镲在正拍 + 八分反拍，且遇到「同拍已有底鼓/军鼓」时优先保留正拍那一击。
- 原样：保留基础型原本细分（含 16 分 / shuffle 摇摆）。
- 密度简化里的镲筛选改成「量化到允许网格并向正拍吸附」，而不是丢弃不在网格上的音符，避免整条只剩反拍。

## 2. 模块更名

「鼓节奏段落」→「歌曲段落分析」，副标题同步改为「选择一个主体段落，或在下方自定义节奏中自己写一小节」。

## 3. 新模块：自定义节奏（图 1 位置改造）

- 删除整块「小节网格预览 + 右侧统计栏」。
- 在「歌曲段落分析」下方新增「自定义节奏」模块：
  - 按分析出的拍号生成一小节，分辨率 16 分音符（4/4 = 16 格，3/4 = 12 格，6/8 = 12 格）。
  - 三轨：底鼓 / 军鼓 / 镲，点击格子切换开关，格子按拍分组（每拍 4 格间加分隔）。
  - 模块自身带一个勾选框（与段落卡片同一组单选）：勾选自定义节奏时，段落卡片全部取消选中；反之亦然。
  - 附「清空」和「载入当前段落」两个小按钮（后者把选中段落的节奏填进编辑器，便于改）。
  - 编辑内容与勾选状态写入 `taiko.settings.v2`，切屏不丢。
- 勾选自定义节奏进入游玩时，编谱以这一小节为骨架（等价于一个临时基础型），仍走活跃度降级、变体与难度收敛。

## 4. 「基础节奏型」模块 → 「谱面难度」

- 模块改名「谱面难度」，第一行是三选项：轻松 / 标准 / 原样（原密度档位，说明文案保留）。
- 第二行新增「倾向风格」八选一：流行、民谣、摇滚、放克、爵士、布鲁斯、电子、世界（内部按拉丁 / 波萨诺瓦处理）。
- 原来的基础节奏型按钮列表不再出现在界面上：基础型仍在后台由段落自动匹配（或由自定义节奏取代），不需要用户手动改选。
- 风格影响动态谱面计算（在骨架之上的编排层）：
  - 流行：装饰最少，镲以正拍为主，过门稀疏。
  - 民谣：更慢的镲细分，几乎不用通鼓，偶尔边击感的军鼓。
  - 摇滚：吊镲落在乐句首，过门用通鼓下行。
  - 放克：底鼓切分多、ghost 军鼓多、镲细分更密。
  - 爵士：叮叮镲为主、踩镲踏板落 2/4 拍、三连摇摆。
  - 布鲁斯：shuffle 摇摆感、装饰少。
  - 电子：四踩底鼓倾向、镲机械均匀、无通鼓过门。
  - 世界：踏板/通鼓交替的拉丁感，军鼓弱化为侧击点缀。
  - 风格只调「概率权重 + 装饰件选择 + 摇摆量」，不改主骨架，保持同歌同设定结果一致。

## 技术调整

- `src/taiko/groovePatterns.ts`：`hatBeats` 支持从正拍开始按 div 生成；新增由自定义一小节转成 `GroovePattern` 的构造函数。
- 新增 `src/taiko/grooveStyles.ts`：八种倾向风格定义（装饰概率、镲件偏好、摇摆量、通鼓/吊镲/叮叮权重）。
- `src/taiko/arrange.ts`：`ArrangeOptions` 增加 `style`，变体/装饰部分改为读风格权重；镲生成改为正拍优先。
- `src/taiko/chartSimplify.ts`：镲降级改为吸附到正拍网格。
- `src/taiko/songStore.tsx`：新增 `customPattern`（三轨 16 分位图）、`useCustom`、`style`，与 `density` 一起持久化到 `taiko.settings.v2`。
- `src/taiko/ChartScreen.tsx`：模块更名、删除小节网格与统计栏、新增自定义节奏编辑器、谱面难度 + 倾向风格控件。
- `src/taiko/FallScreen.tsx`：编谱依赖加入 `useCustom` / `customPattern` / `style`。

## 验证

1. 轻松/标准档位下检查镲位置全部落在正拍（标准允许八分反拍但正拍必有）。
2. 自定义节奏勾选后，段落卡片自动取消选中，游玩谱面骨架与所写一小节一致。
3. 八种风格切换后音符总数与装饰件类型有可见差异，同设定重复生成结果一致。
4. 构建通过，改动源码按目录结构打包到 `/mnt/documents/taiko-custom-groove.zip`。
