# 手机横屏游玩界面优化

## 目标

- 左上角菜单按钮在刘海屏、圆角屏和浏览器工具栏环境下始终可见、可点击。
- 顶部暂停/继续控制始终显示，不再因说明文字换行而被挤出画面。
- 调音台按已选方案改为四轨单行紧凑常驻，尽量少遮挡鼓面。
- 保持舞台 18:9、现有游玩逻辑、谱面、映射和位置捕捉功能不变。

## 界面调整

1. **统一手机安全边距**
   - 根界面接入屏幕安全区域，上下左右控件都避开刘海、圆角与底部手势区。
   - 补齐移动浏览器全高处理，避免地址栏变化导致顶部或底部控件落到可视区外。

2. **顶部控制重新排布**
   - 菜单固定在安全区左上角，并提高触控区域与显示层级。
   - 暂停/继续固定在安全区右上角，手机横屏只保留核心按钮和简短状态。
   - 速度、难度与帮助信息在窄屏隐藏或压缩，不再让按钮换行；较宽屏继续显示完整信息。

3. **底部调音台改为单行紧凑版**
   - 四条音轨始终横向一行排列，每轨显示短名称、音量百分比和滑杆。
   - 去掉手机横屏下占高度的标题说明行，桌面宽屏仍可保留完整说明。
   - 固定最小高度与列宽，防止滑杆和百分比变化引起整体跳动。
   - 调音台整体贴近底部安全区，并控制高度，避免覆盖主要鼓盘。

4. **覆盖窗口兼容**
   - 谱面、映射、位置捕捉窗口继续覆盖舞台。
   - 窗口标题栏和关闭按钮同样避开安全区域；菜单按钮保持最高层级，任何窗口中都能打开。

## 验证

- 在常见 18:9 横屏手机尺寸及带安全区域模拟下检查：菜单、暂停、四轨调音台同时完整可见。
- 检查四条滑杆均可触控，文字不重叠，鼓盘主体未被明显遮挡。
- 检查菜单开关、暂停/继续、谱面/映射/位置捕捉窗口开关均正常。
- 检查桌面界面不退化，并确认预览无构建或运行错误。
