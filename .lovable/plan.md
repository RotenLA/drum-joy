# 修正《红色高跟鞋》开头三下军鼓节奏

## 已确认

- 截掉歌曲开头空白后，截图里的第一组三下军鼓来自轻松/入门档的自动过门规则。
- 当前三下的间隔实际是约 **170ms、341ms**（88 BPM 下为“十六分 + 八分”），所以画面看起来前两颗挤在一起；不是下落透视造成的错觉。
- 原因是“三下军鼓”在一拍内按三等分后又取整到 16 分网格，最终落成不均匀的 `0、1、3` 格。

## 修改

1. 将轻松/入门档的三下军鼓固定为连续八分音符，间隔统一为约 **341ms**。
2. 两下军鼓的过门规则保持原样，其余歌曲、鼓件优先级和四档难度不改。
3. 升级谱面缓存版本，确保本地不会继续读取旧的错误谱面。
4. 用《红色高跟鞋》实际 MIDI 验证裁切后的第一组三下军鼓等距，并检查画面显示与音频节奏一致。
