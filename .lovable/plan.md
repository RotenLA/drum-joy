# 同刻连线贴边与 MIDI 平均速度

## 目标

- 同时刻音符的连线统一从两颗音符各自朝向对方的真实边缘延伸，不再出现一端贴边、一端穿入音符中间。
- 每首歌的显示速度改为根据完整 MIDI 变速表计算的全曲平均 BPM；拍号继续读取 MIDI。
- 后台现有歌曲全部从已上传的 MIDI 批量重算平均 BPM，不重新生成谱面，不影响收藏、成绩或已下载歌曲。

## 实施方案

### 1. 连线统一贴边

- 保留当前椭圆、踏板方块的旋转轮廓计算，以及淡化后的颜色、亮度和后景层级。
- 移除当前会把端点限制在中心距离 45% 内的截断方式；先分别计算两颗音符朝向对方的真实边缘，再绘制边缘之间的线段。
- 两颗音符轮廓已经相交或间距不足时，不把线画进音符内部：缩短或隐藏被覆盖的线段，仅保留可见的边缘延伸效果。
- 三颗及以上同刻音符继续按画面顺序相邻连接，但每一段都独立使用两端真实边缘，保证中间音符左右两侧一致。
- 长音符维持现有规则，不改变长条与普通音符的视觉和判定。

### 2. 从 MIDI 计算全曲平均 BPM

- 保留 MIDI 中完整的 tempo map；谱面音符时间继续按每个变速点精确换算，不改变播放同步。
- 新增全曲平均 BPM：按每段 tempo 实际持续时间加权，等价于用全曲节拍总量除以实际时长；短暂变速不会被过度放大。
- 歌曲卡片、后台列表、下载后载入状态和四档谱面元数据统一使用该平均值，只显示一个 BPM 数字。
- 拍号继续取 MIDI 中的拍号信息；本次不新增手动 BPM 或拍号输入。
- 谱面密度限制改为按真实时间窗口判断，避免变速歌曲仍被曲首 BPM 误导。

### 3. 批量更新已有歌曲

- 后台增加一次性批量重算能力，逐首读取已有 MIDI、计算平均 BPM，并更新歌曲信息与四档谱面中的 BPM 元数据。
- 逐首顺序处理并显示成功/失败结果；单首失败不阻断其余歌曲。
- 只更新 BPM 元数据，不重新编排音符、不改变 MIDI 指纹、不替换音频，也不清除用户已经下载的歌曲。
- 新上传歌曲自动使用相同算法，无需再次手动处理。

### 4. 验证与交付

- 检查不同角度、不同大小、相邻及三音同刻组合，确认连线只接触边缘且不穿过色块。
- 用固定速度、分段变速和连续渐变速度 MIDI 核对平均 BPM、拍号、音符到达时间及后台显示。
- 验证批量重算不会触发谱面重新生成，玩家现有下载、收藏和成绩保持不变。
- 完成检查后，将全部新增和修改源码按原目录打包为 ZIP，并附简短文件清单。

## 技术说明

当前 MIDI 解析已经保存全部变速点，音符时间本身也是按变速表计算；现有问题只是下游把曲首 BPM 当成整首速度。此次会保留曲首速度和完整 tempo map 的内部语义，新增明确的平均速度值，避免破坏已有变速换算。当前连线穿入音符的直接原因是端点被中心距离比例上限截断，轮廓求交公式本身可继续复用。
