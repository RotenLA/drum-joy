# 歌曲后台 + 云端曲库 + 历史演奏

把现在写死在代码里的 5 首歌，换成一个可自助上传的歌曲库：你在后台上传，选歌页直接显示库里所有歌，并把生成好的鼓谱一起存进库，保证所有人打的是同一份谱。

## 1. 开启云端存储

启用 Lovable Cloud，得到歌曲文件存放空间和一张歌曲表（不需要外部账号）。歌曲表记录：标题、艺人（可选）、时长、BPM、拍号、4 条分轨与鼓 MIDI 的地址、上传时间、是否上架。

## 2. 上传后台（/admin）

- 独立页面，进入要先输入账号 `rotenla` 和密码 `045vs007`；口令只保存在服务器端，校验也在服务器端完成，通过后 7 天内免重复输入。
- 上传一首歌：填标题（可选艺人），选 4 条分轨（人声 / 贝斯 / 鼓 / 其他）+ 1 个鼓 MIDI，缺任一项不允许提交。
- 提交后自动完成：读取 MIDI 得到 BPM、拍号、时长；**预生成轻松 / 入门 / 标准 / 困难四档鼓谱并入库**；文件与谱面一起保存。上传进度实时显示。
- 歌曲列表可搜索、改标题、上架/下架、删除、重新生成四档谱面（MIDI 换了就用这个）。

## 3. 谱面统一（你提的备份点）

四档谱面在上传时就生成好存进库，客户端只下载、不再自己生成，所以任何用户、任何设备、任何时间打同一首歌，谱面完全一致。谱面同时按「MIDI 内容指纹 + 难度」记录版本，MIDI 更新后旧谱面自动失效重建。若云端暂时取不到谱面，客户端仍可本地生成兜底，不至于玩不了。

## 4. 选歌页改版

- 歌曲卡片变大更醒目：标题更大、艺人/时长/BPM/拍号一行副信息、选中态橙色边框加左侧橙色竖条 + 「已加载」角标，加载时卡片内橙色进度条与百分比。
- 卡片下方加搜索框：输入即过滤标题与艺人，无结果给出提示。歌多了自动分页/滚动加载，不会一次拉全部音频。
- 「选择歌曲」右侧新增「历史演奏」标签页：两个标签切换，显示本机最近演奏记录（歌名、难度、速度、准确率/连击、时间），点一条直接重新加载该歌并套用当时的难度与速度；可清空。历史只存本机（按你的选择），后续要跨设备再接玩家身份。

## 技术说明

- 新增 `songs` 表 + `song_charts` 表（难度、MIDI 指纹、谱面 JSON），公开只读上架歌曲；写入只走后台管理员通道。音频与 MIDI 放公共存储桶，走 CDN 直连下载，保留现有带进度的下载逻辑。
- 后台口令用服务端环境变量 + 加密会话（timing-safe 比较），不进前端包。
- 上传处理与谱面预生成在服务端函数里完成，复用现有 `midiFile.ts` 解析与 `difficulty.ts` 的 `buildPlayChart`，确保与客户端结果一致。
- `presetSongs.ts` 改为从云端曲库读取列表（保留资源地址回落逻辑）；`chartCache.ts` 增加「先取云端谱面、失败再本地生成」的分支。
- 历史记录存 `localStorage`（`taiko.history.v1`，最多 100 条）。
- 现有 4 首歌作为初始数据迁进新库，选歌体验不中断。
