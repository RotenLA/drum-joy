# 游玩屏重做：舞台鼓组下落式（Drum Hero 式）

推翻 synthwave 场景（落日/山脉/霓虹网格全部删除），只保留它的**相机视角**（略俯视的透视）。新场景参考 Drum Hero 截图：深色舞台，中部一套立体鼓组（9 部件、各自颜色），音符从鼓组后方消失点沿透视车道由小变大滑向玩家，统一落在鼓组前方**一条判定光线**上，命中时对应鼓件发光弹跳。

## 一、场景构图（Canvas 单画布，伪 3D，不引 WebGL）

```text
┌────────────────────────────────────┐
│ 顶部：细进度条 / 得分(左) / 曲名+BPM(右) │
│        连击数（浮在鼓组上方，大号）        │
│  ～～ 消失点（车道收束处，鼓组后方） ～～   │
│      ╲ 音符车道（透视收束） ╱          │
│   🥁 立体鼓组（9 部件，调色板颜色）      │
│  ─────── 判定光线（一条横线） ───────   │
│   舞台地面（暗色反光，弱透视纹理）        │
└────────────────────────────────────┘
```

- **背景**：歌曲封面继续铺底但压得更暗（舞台后场氛围），加顶部聚光灯渐变；无落日、无山脉、无霓虹网格
- **鼓组**：第一人称鼓手视角（踩镲最左 → 吊镲左上 → 高/中通中上 → 军鼓左下 → 底鼓中央大鼓 → 地通右侧 → 叮叮镲右上；两个踏板在最前方底部）。鼓身画圆柱体（顶面椭圆 + 侧面渐变），镲片画扁椭圆带支架，底鼓最大。每个部件用调色板色做描边/泛光，本体保持深灰金属质感，颜色只作"身份标识"
- **车道与音符**：每个部件一条车道，从消失点收束到判定线；5 分区模式下车道仍按真实部件位置落点（保持颜色学习机制）。音符为带部件色发光的圆角芯片，近大远小
- **判定线**：鼓组前方一条横贯的浅色光线，所有音符都落在这一条线上；命中（键盘模拟/自动演奏）时该段光线闪白
- **命中反馈**：对应鼓件瞬间放大回弹 + 颜色增亮 + 火花粒子；镲片带轻微摆动
- **HUD**：连击数大号浮在鼓组正上方（参考截图的 MAX COMBO），顶部细进度条，左上得分、右上曲名/BPM

## 二、保持不变的部分

- 5分区 / 9分区全局设置、0.5x–2x 速度、键盘模拟击打、自动演奏闪光、localStorage `taiko.settings.v1`
- 部件色板继续在 `laneLayouts.ts` 集中管理
- 经典横向模式、谱面屏、映射屏不动；真实 MIDI 判定仍留到下一轮

## 三、文件改动

- **新增** `src/taiko/stageRenderer.ts`：舞台/鼓组/车道/音符/判定线/HUD 全部绘制 + 透视投影（复用现有 project 思路）+ 鼓件命中动画与粒子

- **修改** `src/taiko/FallScreen.tsx`：换 renderer import；命中时把闪光目标从"分区"扩展到"部件"（鼓件动画需要 partId）

## 技术说明

- 透视：沿用现有 `project(x, t)` 思路（t=0 远/消失点，1 近/判定线），车道 x 在远/近端之间插值，使音符视觉上"从鼓组方向飞来"
- 鼓组锚点为归一化坐标常量，摆位/大小不满意只改 `laneLayouts.ts` 一张表
- 粒子与命中动画用 `performance.now()` 差值驱动，无额外状态库；全部 Canvas 2D，Electron 里零新依赖
