# 市场部反馈：稳定性 + 快速改进 + 全球排行榜

## 一、下载与选歌流程（稳定性）

1. **点中歌曲不再自动下载**：点击歌曲只展开卡片。卡片内直接显示难度、成绩区（有分数就显示分数和评级）、手机音色等全部选项。
2. **右下按钮分两种状态**：
  - 未下载：显示「下载」，点击后按钮变成进度环，可以再点一下取消。
  - 已下载：显示「开始」，点击直接进入演奏，不再弹出进度页。
3. **下载好的歌存在本机**：四条分轨和 MIDI 存进浏览器的持久存储，重启 App 后仍然有效；卡片上加「已下载」标记。
4. **下载时可以随意切歌**：下载在后台进行，同时只下一首。切到别的歌、展开别的卡片都不受影响；可以取消下载。
5. **防死机**：下载只保存原始文件，不在下载时解码；点「开始」时才解码当前这首，并释放上一首占用的内存。解码失败时显示「重试」，不会卡死在页面上。

## 二、快速改进

6. **调音台**：只保留一个「背景音乐」滑块。0–100% 对应静音到 +6dB，80% 等于原始音量，默认 80%。鼓轨保持静音。
7. **踏板反馈**：踩下踏板时，踏板图片立即变亮（有颜色和光晕），在所有难度下都有，教学里也一样。
8. **击中与连击特效**：判定文字放大约 1.6 倍，并加弹跳动画；连击数随连击增长逐级放大、变色（10/30/50/100 连击各有一档），断连时有收缩效果。
9. **歌曲进度条**：演奏画面顶部加一条细进度条。
10. **画面提亮**：减轻背景封面的压灰，提高轨道和鼓面的亮度，整体更明亮欢快。

## 三、每首歌全球排行榜

11. 每首歌、每档难度，按最高分列出前 20 名，同时显示「我的排名」。
12. 入口：展开的卡片成绩区旁加「排行榜」按钮，打开弹窗；结算页显示本次成绩的排名，破个人纪录时显示「新纪录」。
13. 玩家名称：宿主目前只给 user_id。先显示遮挡后的 id（例如 `玩家 ••3456`）；如果宿主能提供昵称接口（例如 `__pd2uGetUser()` 返回里加上 `name`），我们会自动显示昵称。

## 暂不做

耳机只听到鼓声、风格背景、谱面难度重做、分享和挑战。

## 技术细节

- 新增 `songDownloads.ts`：用 IndexedDB 存储每首歌的原始文件，以 song_id + midi_fingerprint 作为键；提供下载队列（AbortController 可取消）、进度订阅和已下载查询。`songLibrary`/`player` 优先从本地读取。
- `SongPicker`/`CardControls`：展开卡片和加载流程拆开；开始按钮根据下载状态显示「下载 / 进度 / 开始」。
- `player`/`stems`：只把背景音乐三轨合成一路增益，增益系数 = (v/0.8) 换算，上限 +6dB 由线性值 1.995 控制；设置迁移到新的存储键。
- `stageRenderer`/`columnRenderer`：踏板按下时发光；新增判定字弹跳、连击分档缩放、进度条；调整背景压灰透明度。
- 数据库：用 `play_bests` 生成排行榜，新建 server function `getLeaderboard(song_id, difficulty)`，只返回名次、遮挡后的 id、分数、准确率和评级，不暴露完整 id；`getMyRank` 返回自己的名次。
- 九语言补齐新增文案。
- 交付：tsgo/构建通过，Playwright 双端检查通过后，打包 zip 放到 /mnt/documents/，并附文件清单。
