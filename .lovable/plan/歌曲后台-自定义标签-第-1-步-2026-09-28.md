# 歌曲后台：自定义标签（第 1 步）

本轮只改后台；选歌页歌单化（第 2 点）和难度解锁（第 3 点）等后台弄好后再做。

## 后台界面（/admin）

在「上传新歌」和「曲库」两块中间新增 **标签管理** 区：
- 新建标签（输入名称 + 添加），列表显示每个标签及其歌曲数
- 可改名、删除（删除只解除关联，歌曲本身保留）
- 可上下调整顺序（以后首页歌单按此顺序排列）

**上传新歌**：表单多一行「标签」，可多选（一首歌可属于多个歌单）；不选也能上传，归为「未分类」。

**曲库列表**：每首歌一行多一组标签小徽章，点开可勾选/取消所属标签；顶部加标签筛选（全部 / 某标签 / 未分类）。

## 需要你确认的一点
默认按「一首歌可属于多个标签」设计（更灵活，比如同时在「摇滚」和「热门」）。若只要单选，告诉我即可。

## 技术说明
- 新表 `song_tags`（id、name 唯一、sort_order、created_at）与关联表 `song_tag_links`（song_id、tag_id，联合主键，均级联删除）；GRANT + RLS：公开只读（为第 2 步歌单准备），写入只走后台管理员服务端函数（service role）。
- `admin.functions.ts` 新增 listTags / createTag / renameTag / deleteTag / reorderTags / setSongTags，均经 requireAdmin 校验；listAllSongs 附带每首歌的 tag_ids；saveSong 接收 tagIds。
- `admin.tsx` 增加标签管理区、上传表单多选、曲库行标签编辑与筛选。
- 选歌页暂不改动，现有玩法不受影响。
