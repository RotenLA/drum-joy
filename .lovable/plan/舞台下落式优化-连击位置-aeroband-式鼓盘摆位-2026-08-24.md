# 舞台下落式优化：连击位置 + AeroBand 式鼓盘摆位

基于当前「舞台下落式」实机效果的两处优化，不改玩法逻辑与判定。

## 一、连击数移到左上角

- 连击大数字从「中上方悬浮」移到左上角，放在 SCORE 分数正下方（左上对齐）
- 保持大号斜体白色发光样式，`COMBO` 小字标签紧随其后
- 中上方（消失点附近）完全腾空，不再有任何 HUD 遮挡音符

## 二、鼓盘摆位改为 AeroBand 布局（图2 参考），压缩到下 1/3 屏

参考 AeroBand 鼓位图：上排 4 件、中排 3 件、下排 2 踏板。扇形放射车道保留（音符仍从顶部消失点飞向各自鼓盘），但鼓盘整体压缩到屏幕下 1/3，给下落色块留出约 2/3 屏的飞行空间。

```text
┌──────────────────────────────┐
│ SCORE                        │
│ 0014280    ← 连击紧跟其下      │
│ 119 COMBO          曲名/BPM   │
│                              │
│         ～消失点～            │
│      ╲ ╲ │ ╱ ╱  （音符空间）  │
│                              │
│   吊镲   高通   中通   叮叮镲   │ ← 上排（偏远偏小）
│     踩镲   军鼓   地通         │ ← 中排
│       踩镲踏板   底鼓          │ ← 下排（最近最大）
└──────────────────────────────┘
```

- **上排**（cy≈0.66，偏小）：吊镲 crash(0.16) → 高通 highTom(0.38) → 中通 midTom(0.62) → 叮叮镲 ride(0.84)
- **中排**（cy≈0.80，中等）：踩镲 hihat(0.20) → 军鼓 snare(0.50) → 地通 floorTom(0.80)
- **下排**（cy≈0.92，最大）：踩镲踏板 pedalHat(0.35) → 底鼓 kick(0.65)
- 近大远小：半径随排次递增；颜色、kind（drum/cymbal/pedal）画法不变
- 车道/音符投影逻辑不变：锚点变了，车道终点与音符落点自动跟随

## 三、文件改动

- **修改** `src/taiko/laneLayouts.ts`：仅重写 `PAD_ANCHORS` 一张表（9 个锚点的 cx/cy/r）
- **修改** `src/taiko/stageRenderer.ts`：`drawHud` 中连击块从中央移到左上分数下方（字号略收，避免挤压）
- 其他文件（FallScreen、TaikoShell、分区/键位映射）不动

## 验证

改完后跑预览截图确认：连击位于分数下方、鼓盘呈 AeroBand 三排布局压在下 1/3、音符落到各自鼓盘无错位。
