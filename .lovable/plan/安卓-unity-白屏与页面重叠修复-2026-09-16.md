# 安卓 Unity 白屏与页面重叠修复

## 目标
恢复上个安卓正常版本的页面承载方式，同时保留本轮新增的 FPS、-24dB 开头裁切、17:7 总窗口、3:14 分栏和 14:5 演奏区。

## 实施
1. **回退高风险深色改动**
   - 撤销页面入口中新加的强制深色标签与内联样式，避免整份入口文件改变安卓 Unity WebView 的加载行为。
   - 深色改为样式层直接提供，并加入旧版安卓 WebView 可识别的颜色兜底；不依赖系统深浅模式。

2. **加固页面互斥与尺寸兼容**
   - 保持左栏和右侧独立页面结构，游玩、谱面、映射、位置捕捉任一时刻只渲染一个。
   - 为 `dvh`、`min()` 和比例尺寸补充传统 `vh/vw` 兜底，防止旧 WebView 无法解析后失去高度、导致内容叠放。
   - 保留安卓触摸滚动规则，非游玩页面继续独立上下滑动。

3. **保留有效的新功能**
   - 保留游玩区右上角 FPS。
   - 保留 -24dB 静音识别及四轨/MIDI 同步裁切。

4. **验证与交付**
   - 检查构建和运行错误。
   - 用安卓横屏触摸环境验证：深色背景、四页面互斥、17:7/14:5 比例、设置页滚动、FPS 可见。
   - 输出新的修复压缩包，附修改文件清单，供本地覆盖。

## 技术说明
当前网页本身构建通过；问题只出现在安卓 Unity 环境。修复采用“回到上一版稳定承载方式，再以兼容 CSS 实现深色”的策略，避免继续叠加强制主题配置。
