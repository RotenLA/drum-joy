# 谱面设置与歌曲信息精简

## 修改内容

1. **统一橙色选中态**
   - 画质 Auto/High/Mid/Low、下落速度、难度、鼓音色等所有可选按钮，选中后统一使用当前橙色强调色。
   - 未选中状态保持深色底与浅色文字，避免白色选中块破坏整体风格。

2. **精简歌曲信息**
   - 删除歌曲列表下方整条独立信息栏，包括播放按钮、播放进度、音符数和重复歌名。
   - 歌曲加载完成后，在选中歌曲卡片的歌名右侧显示：`时长 · BPM · 拍号`。
   - 下载中仍显示百分比；未加载歌曲仍显示“点击加载”。

3. **修复鼓组下拉菜单可读性**
   - 下拉框及展开选项统一为深色背景、亮色文字；当前选项使用橙色强调，确保 Unity WebView 和浏览器内都清晰可见。

4. **隐藏重新生成谱面**
   - 暂时不显示 “Regenerate Chart / 重新生成谱面” 按钮，保留内部谱面生成能力，不影响切换难度时生成对应谱面。

5. **调整延迟默认值**
   - Visual Offset 默认设为 `+90ms`，取空气鼓输入常见 80–100ms 延迟的中值，让音符更早到达以补偿输入链路。
   - Judge Offset 默认设为 `+20ms`，补偿网页端鼓声触发的预估延迟。
   - 升级校准设置版本，使这组新默认值实际生效；用户之后仍可通过滑杆或自动校准继续微调。

6. **默认语言改为中文**
   - URL 没有 `?lang=` 或语言码无法识别时，默认使用简体中文。
   - 已支持的 `zh/zh-TW/ja/fr/ko/de/it/es/en` 参数行为保持不变。

## 验证与交付

- 检查歌曲未加载、下载中、加载完成三种状态。
- 检查所有选中态颜色、鼓组下拉菜单、两项偏移默认值和无语言参数时的中文界面。
- 检查英文及其他语言 URL 参数仍正常。
- 打包全部新增/修改源码为 ZIP，并附简短文件清单。
