# 语言精简为中文 + 英文，并补齐漏翻

## 目标
- 只保留两种语言：简体中文、英文。
- `?lang=` 以 `zh` 开头（zh / zh-CN / zh-Hans / zh-TW / zh-HK 等）→ 简体中文；其余任何值或未带参数 → 英文。
- 全域排查所有用户能看到的文字，确保英文模式下没有残留中文、中文模式下没有残留英文。

## 要做的事
1. 语言判定：改为只有「中文 / 英文」两档，默认英文（与现有记忆规则一致）。
2. 删除繁中、日、韩、法、德、意、西 7 份字典，以及教学步骤、教学按钮、旧浏览器提示页里的多语言分支，只留中英。
3. 页面标题、`<html lang>` 随语言切换（中文标题 / 英文标题）。
4. 漏翻排查与修复（逐文件过一遍）：
   - 设备连接提示（适配器 / 左右鼓棒 / 踏板 已连接·已断开）目前只有中文，补英文。
   - 教学「上一步」按钮、全局设置里的「当前实际画质」、MIDI 映射页的提示和计数、实验室说明等。
   - 非界面文件里直接返回给用户的文字（评级、提示、错误弹窗、下载进度、帮助文案等）。
   - 启动失败页、旧浏览器提示页保持中英双语或按语言显示。
   - 后台 /admin 是内部工具，保持中文，不纳入本次。
5. 用脚本扫描英文模式下的界面，确认无汉字残留；桌面与手机横屏各截图检查选歌、歌单详情、设置、游玩、结算、教学。
