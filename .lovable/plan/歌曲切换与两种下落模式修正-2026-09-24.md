# 歌曲切换与两种下落模式修正

## 目标
- 点击另一首歌曲后，当前展开卡片立即收拢；新卡片单独展开并显示加载进度。
- 横排下落取消所有同刻连线，恢复踩镲踏板长音符，并让闭镲、开镲严格共用同一列。
- 横排模式继续以 Height / p 选择部件和识别下挥；y 角仅驱动鼓棒轻微上下动作，不参与选列或命中。
- 舞台下落移除动态包裹，恢复为更粗、更清晰的混色发光连线。

## 实施步骤

### 1. 歌曲卡片切换
- 将“正在加载”与“已加载歌曲”的展开状态拆开。
- 新歌点击瞬间隐藏旧歌的设置、开始按钮和展开宽度，再只展开正在加载的新歌。
- 加载失败时新卡收拢；已加载资源仍可保留，不影响再次选择。

### 2. 横排音符表现
- 完全移除横排模式的同刻分组与包裹线，只保留各列独立音符。
- 按现有谱面 `holdMs` 绘制踩镲踏板长音符：头部、持续轨迹和尾部沿同一列下落，并正确经过判定线。
- note 42（闭镲）和 note 46（开镲）统一映射到 hihat 列，位置、宽度和判定点完全一致；仅保留原有音符属性差异。

### 3. 横排鼓棒角度
- Height / p 仍按当前难度启用的部件划分横向列，并继续作为下挥触发轴。
- y 角经过与舞台模式一致的有效角度范围限制后，仅映射为棒尖小幅纵向位移。
- 超出范围时钳制，不让棒尖越过判定区域；不改变 MIDI 踏板逻辑，也不让 y 角影响命中部件。

### 4. 舞台同刻连线
- 删除舞台模式现有的动态闭合包裹轮廓。
- 同刻音符中心之间绘制单条较粗光柱：两端颜色按鼓件色平滑混合，中心有清晰亮芯，外围只有轻柔辉光。
- 低画质关闭外围辉光但保留主光柱；三颗以上按相邻音符连续连接。

## 验证
- 快速连续点击不同歌曲，确认旧卡立即收拢且只有一个展开卡。
- 用包含 note 42、note 46、note 44 长按和多音同刻的谱面验证横排模式。
- 模拟 Height / p 与 y 输入，确认 p 选列和触发、y 仅产生受限的轻微上下动作。
- 分别检查 5/7/9 列、舞台模式、教学与正式歌曲，并验证桌面和手机横屏无重叠、无运行错误。
- 将全部新增/修改源码按目录结构打包为 ZIP，并附简短文件清单。
