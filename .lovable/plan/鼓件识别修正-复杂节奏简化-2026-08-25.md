# 鼓件识别修正 + 复杂节奏简化

## 问题一：镲被认成军鼓、军鼓没被认出

现在的做法是三个独立的滤波器各自做 onset 检测：

- 军鼓带 = 1200–5000 Hz，踩镲带 = 6000 Hz 以上。
- 镲片（hi-hat / crash / ride）的主要能量恰好落在 2–8 kHz，因此**每一次镲都会在“军鼓带”里触发一次 onset**，被写成军鼓。
- 真实军鼓的辨识特征是「150–250 Hz 鼓腔共振 + 2–5 kHz 短促噪声、衰减快」，只看 1200–5000 Hz 无法与镲区分，遇到镲密集的段落军鼓反而被吞掉。

### 新方案：先找 onset，再对每个 onset 分类

1. 用全频带（宽带 + 高频加权）做一次统一 onset 检测，得到全曲击点时刻，避免同一击点被三条链路各算一次。
2. 对每个击点取一段短窗（约 60 ms 前 / 180 ms 后），计算特征：
  - 低频能量（30–120 Hz）
  - 鼓腔能量（150–300 Hz）
  - 中高噪声能量（2–6 kHz）
  - 极高能量（8 kHz 以上）
  - 衰减时长（能量掉到峰值 25% 所需时间）、谱心
3. 分类规则（按顺序）：
  - 低频占主导且极高能量弱 → 底鼓
  - 有明显鼓腔能量 + 中高噪声、衰减短（< ~120 ms）→ 军鼓
  - 无鼓腔能量、极高能量强、衰减长 → 镲（踩镲/镲片）
  - 同一时刻允许同时判定底鼓与手击件（底鼓+镲同拍很常见）
4. 每个类别的判定阈值按整曲统计量自适应（用各特征的分位数而不是固定数值），避免不同混音一刀切。
5. 段落卡片仍是「底鼓 / 军鼓 / 踩镲」三行，但由分类结果驱动，会先用你给的 Mixdown-ACE.mp3 验证：军鼓应出现在 2、4 拍附近，镲成为高频细分，两者不再混淆。

## 问题二：复杂节奏进入游玩太难

主体节奏若本身是 16 分密集型，直接铺满全曲会打不动。加入**谱面密度档位**（谱面屏一个三选项：轻松 / 标准 / 原样，默认标准），编谱时按档位简化：

- **简化规则**（按优先级丢弃）：
  1. 先保留每小节强拍与反拍骨架（底鼓在 1/3 拍位、军鼓在 2/4 拍）。
  2. 镲的 16 分细分降为 8 分；轻松档再降为 4 分。
  3. 同一时间点（< 40 ms）多件同响时，只保留优先级最高的一件（底鼓 > 军鼓 > 开/闭镲 > 其他）。
  4. 每小节音符数上限：轻松 6、标准 10、原样不限；超出时按「距离强拍越远越先丢」排序删除。
  5. 相邻音符最小间隔限制（轻松 160 ms / 标准 110 ms），避免人手打不出的连打。
- 5 分区在此之上继续维持现有鼓件白名单，9 分区的装饰音（吊镲/通鼓/叮叮镲）数量也随档位缩减。
- 简化仍是确定性的（同歌同主体同档位结果一致）。
