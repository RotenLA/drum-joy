# 舞台下落式 v5：EVA 封面墙 + 镜面地板 + 阴影/踏板修正

## 改动内容（2 个代码文件 + 1 个新素材）

### A. 背景：专辑封面墙 + 镜面地板（stageRenderer.ts）

思路：封面图就是「挂在墙上的画」，地面是深色亮光地板，带一点倒影。

- 新增素材 `src/assets/stage-wall.jpg`（用户上传的 EVA 图，1920×975），替换 `stage-bg.jpg`（后者从代码引用中移除，本地可删）。
- `drawBackground` 重写为两段式：
  - **墙面（0 ~ SEAM_SCREEN_Y=0.60）**：图片 cover 铺满墙带，用 `ctx.filter = "saturate(0.55) brightness(0.65)"` 压灰压暗（「灰一点点」），上方再叠一层深色渐变保证音符可读性。
  - **地板（0.60 ~ 1.0）**：深色基底 + 倒影——把墙面图像底部一段垂直翻转画进地板区，透明度约 0.15 并随深度渐隐（渐变遮罩），加轻微 `blur(3px)` 模拟磨砂镜面；墙根处加一条细高光缝增强「镜面」分界。
  - 保留顶部聚光灯与整体压暗层；`BG_SEAM_Y` 对齐逻辑删除（新图无墙地分界线，按墙带直接裁切）。

### B. 接触阴影修正（stageRenderer.ts）

问题根因：阴影画在鼓面中心下方 `cy + ry*0.85` 处，但鼓腔侧面实际延伸到 `cy + depth`，阴影悬在半空 → 鼓看着是浮的。

- 阴影锚点改为各部件的**地面接触线**：鼓 = 鼓腔底缘（cy + depth + ry），镲 = 镲片底缘，踏板 = 楔块底边。
- 阴影更柔更淡（blur 加大、alpha 0.5→0.35），宽度随部件半径 1.15 倍。
- 不删除阴影——统一地板视角仍需要它，只是落到正确的地面上。

### C. 踏板等大 + 视角倾斜（laneLayouts.ts + stageRenderer.ts）

- `kick` r: 0.055 → **0.045**（与 pedalHat 一致，左踏板大小为基准）。
- `drawSquarePad` 重写为**透视楔块**：
  - 顶面改为梯形：后缘（上方）收窄约 25% 并上移，前缘（下方）最宽——与鼓的俯视压扁同一相机角度，不再是正对着屏幕的方片。
  - 前缘加一条薄亮边（踏板前沿金属感），侧沿保持低趴厚度。
  - 命中描边/白闪跟随同一梯形轮廓。

## 不动

音符飞行/判定、车道收束段、鼓盘摆位（除 kick 半径）、HUD、其他界面。

Playwright 实机截图核对：封面墙灰度与倒影效果、鼓是否「落地」、两踏板等大且角度与鼓一致。确认后打包 `taiko-stage-fall-v5.zip`（stageRenderer.ts + laneLayouts.ts + stage-wall.jpg + 文件清单，注明 stage-bg.jpg 可删）。
