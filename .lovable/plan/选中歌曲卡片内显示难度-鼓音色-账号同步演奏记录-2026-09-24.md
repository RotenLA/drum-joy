# 选中歌曲卡片内显示难度/鼓音色 + 账号同步演奏记录

## 1. 选中卡片内加操作区（图2）
- 卡片中部空白处放两行：
  - **难度**：轻松 / 入门 / 标准 / 困难 四个按钮，选中为橙色。每个按钮下方显示该难度的「最佳分数 · 最高准确率」和进度条（打过的最远进度，打完为 100% 并显示完成标记）；没玩过显示「未游玩」。
  - **鼓音色 开/关** 按钮 + **鼓组**下拉。
- 这里改的和设置弹窗里是同一份全局值，两边同步；设置弹窗保留原样。
- 手机横屏高度不足时，操作区字号与间距自动缩小，不挤到「开始」按钮。

## 2. 账号同步（存在 Lovable Cloud）
- 进入时调用 `window.__pd2uGetUser()` 取玩家 id（字符串，不转数字）。
- 有 id：每次演奏结束（完成或中途退出）把记录写到云端；选歌卡片和「历史演奏」都从云端读，换设备也一致。
- 无 id（返回 null 或 ""，含浏览器直接打开）：继续只存本机，行为同现在。
- 首次拿到 id 时，把本机已有的历史记录一次性上传合并，避免丢失。
- 每首歌每个难度保存一条「最佳成绩」：最高分、最高准确率、最大连击、最远进度、游玩次数；另存最近 100 条历史明细。

## 3. 安全说明（需要你知晓）
- 宿主只给了 id，没有签名/令牌，网页无法证明这个 id 是真的。写入只能经服务端校验格式与数值范围，但理论上知道别人 id 就能伪造其成绩。
- 若以后要排行榜等防作弊需求，需要 Unity 端额外提供签名票据，届时再加。

## 技术细节
- 新表 `play_records`（user_id 文本、song_id、difficulty、score、accuracy、max_combo、progress、completed、played_at）和 `play_bests`（user_id+song_id+difficulty 唯一）。表开启 RLS 且不对前端开放，读写全部走服务端函数（admin 客户端 + zod 校验）。
- 新增 `src/lib/plays.functions.ts`：`submitPlay`、`getBests(userId)`、`getHistory(userId)`、`importLocalHistory`。
- `history.ts` 增加云端分支；`SongPicker.tsx` 选中卡片渲染操作区；复用 GlobalSettings 里的难度/鼓音色/鼓组状态。
- 分数沿用现有结算的准确率/连击；若结算目前没有独立「分数」，按判定加权计算一个 0~1,000,000 分。
