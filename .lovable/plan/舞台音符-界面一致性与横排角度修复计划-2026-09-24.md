# 舞台音符、界面一致性与横排角度修复计划

## 1. 舞台同刻连线
- 连线不再从音符中心穿过：根据两端音符的椭圆/色块边界计算交点，线段只连接两个外轮廓之间的空隙。
- 外层光柱和内层亮芯同步加粗，仍按两端鼓件颜色渐变；保持 15ms 同刻规则、三颗以上相邻连接和现有层级。
- 连线尺寸改用当前统一音符尺寸，不再沿用会受鼓盘大小、重击标记影响的旧尺寸公式。

## 2. 长音符形状与流动效果
- 舞台和横排两套长音符都改为真正的直角矩形轮廓，彻底移除 `roundRect`、圆头和圆角收边。
- 保持头尾宽度随透视变化，但两端均用垂直于下落方向的平直切边。
- 将单个亮斑机械地从头扫到尾，改为连续循环的分层流光：低对比底色 + 两道错开的柔和亮带，循环衔接不跳变；低画质仅保留静态渐变，避免额外性能负担。

## 3. 同类选项与窗口尺寸统一
- 先统一截图中的暂停菜单：继续、重新开始、退出采用同宽、同高、同字号和同内边距，长文案也不改变按钮外框。
- 盘点当前选歌、全局设置、教学、暂停与结算界面；同一组选择项统一高度、最小宽度、字号、圆角和间距，弹窗统一最大宽度、内边距和关闭按钮尺寸。
- 保留不同用途控件应有的层级差异，不把所有按钮强行做成一种大小；重点消除同一界面、同一组选项内的忽大忽小和文字撑框。
- 使用现有统一按钮样式，替换这些界面中重复的临时按钮写法。

## 4. 横排下落角度识别
- 修正目前“同一个俯仰值既负责横向选列、又负责识别下挥”造成的互相牵制。
- 横排模式按宿主两轴分工：`p / Height` 只负责九个部件的横向落点选择；`y / YAW` 负责轻微上下动作与下挥触发。
- `y` 使用与舞台模式一致的有效角度边界、下挥速度/行程/触底规则；超界仅钳制显示，不把鼓棒锁在某一列。
- 击中时用触底帧的 `p / Height` 确定最终部件，挥击途中经过其他列不触发；左右棒继续独立跟踪，踏板仍只走 MIDI。
- 横排画面中的棒尖纵向反馈同步使用同一套 `y` 范围，确保视觉动作和实际触发一致。

## 验证与交付
- 用固定测试谱检查：两音与三音同刻连线都止于色块边缘；普通音符尺寸一致；两种模式的长音符均为直角且流动连续。
- 检查窄屏、横屏和中英文长文案下，同组选项及弹窗尺寸一致、无溢出或遮挡。
- 用模拟姿态流逐列测试横排模式：保持 Height 可选列，YAW 下挥可触发，快速跨列不误触，双棒互不锁死。
- 完成类型检查、构建与页面实测后，按原目录结构打包 ZIP，并附文件清单。
