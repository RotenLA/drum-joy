# 角度触发灵敏度调低

## 目标

测试模式（律动大师）里，鼓棒角度判定太灵敏，轻动一下也会出声。调严判定门槛，只认「明确用力的敲击」。

## 改动（只动 src/taiko/gestureHit.ts 一个文件）


| 参数                    | 现在     | 调成     | 效果                   |
| --------------------- | ------ | ------ | -------------------- |
| ARM_SPEED 触发角速度       | 170°/s | 200°/s | 要挥得更快才算开始敲击，慢速小动作不触发 |
| MIN_TRAVEL_DEG 最小下探幅度 | 6°     | 10°    | 轻微抖动、原地晃动不会误判        |
| REFRACTORY_MS 同棒最短间隔  | 85ms   | 120ms  | 反弹抖动不会连出两下           |
| RELEASE_SPEED 触底判定    | 55°/s  | 45°/s  | 下探要更明确地收住才出声         |


力度映射区间同步微调，保证正常用力敲击力度不受影响。

## 验证

- bunx tsgo --noEmit
- Playwright 模拟鼓棒姿态流：慢速小幅移动不出声、正常敲击正常出声
- 打包 zip（只含 gestureHit.ts）放 /mnt/documents

## 说明

参数会保留在文件顶部常量区，后续要再调紧/调松只需说「再灵一点 / 再钝一点」。
