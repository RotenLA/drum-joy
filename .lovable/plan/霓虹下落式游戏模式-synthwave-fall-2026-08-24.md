# 霓虹下落式游戏模式（Synthwave Fall）

把游玩屏从「太鼓横向单轨」升级为「3D 透视下落式」：参考图1 的 synthwave 场景（视角比参考图再俯视一点），分区铺在地面透视网格上（不是图2 的垂直俯视图），音符沿分区滑向玩家，月亮位置放 HUD，底层铺歌曲封面。

## 一、游戏模式决策

- **下落式设为默认游玩模式**；现有横向太鼓模式保留为「经典横向」，游玩屏顶部一键切换
- **分区为全局设置**（localStorage 持久化），两档：
  - **5分区（默认，易上手）**：下半区 左踏板(踩镲踏板 44) + 右踏板(底鼓 35/36)；上半区 左区(开/闭镲 42/46、吊镲 49/52) + 中区(军鼓 38/40、高通 48/50、中通 47) + 右区(叮叮镲 51、低通/地通 41/43/45)
  - **9分区（进阶）**：9 个部件各自独立分区 —— 踩镲踏板、底鼓、踩镲(42/46)、吊镲(49/52)、军鼓(38/40)、高通(48/50)、中通(47)、地通(41/43/45)、叮叮镲(51)
- 分区左右排布按鼓手视角（同图3 鼓位图）：踩镲最左 → 吊镲 → 高通 → 军鼓居中 → 中通 → 地通 → 叮叮镲最右；两个踏板在更靠近屏幕下方的低位横条
- **5分区里音符仍按真实部件颜色着色**： merged 分区内玩家靠颜色逐渐记住 9 部件位置，平滑过渡到 9分区

### 我推荐的易上手设计（回答"更好的方案"）

1. 默认 5分区 + 颜色学习机制（上条）
2. 判定线处显示「下一个音符」的落点辉光提示，提前预告落区
3. 下落速度可调（0.5x–2x），与分区模式一起存全局设置
4. 本轮暂不接真实 MIDI 判定：键盘按键模拟各分区击打闪光（预览里可调手感），判定/连击逻辑下一轮接现有 MIDI 管线

## 二、视觉：Synthwave 场景（Canvas 单画布）

- **底层**：歌曲封面图铺满并压暗+模糊，透出霓虹色调；本轮先生成一张 synthwave 风格演示封面
- **天空**：紫蓝渐变星空 + 经典横切线霓虹落日（黄→品红渐变、扫描线缺口）
- **月亮=HUD**：落日外圈是环形播放进度条，落日中心是大号连击数，下方得分与曲目名/BPM
- **两侧**：线框山脉剪影（青色描边微光），远景静止
- **地面**：透视霓虹网格向消失点收束，相机俯仰角比图1 略高（可调常量），分区梯形面板按图2 的相对布局投影到地面
- **分区**：每区一个发光描边梯形，边缘色 = 该区代表色；踏板区更矮更宽、位置更低
- **音符**：圆角矩形芯片（图2 风格），带部件色发光，从消失点由小变大滑向判定线；判定线是底部一道霓虹光梁，命中（键盘模拟）时光梁+分区闪一次
- **部件色值（取自图3）**：吊镲 `#F1E12F`、高通 `#F978C1`、中通 `#90FBE9`、叮叮镲 `#8341F1`、踩镲 `#F48419`、军鼓 `#5D8CF4`、地通 `#95F96F`；两个踏板图3 未给，定为 底鼓 `#FF4D4D`（红）、踩镲踏板 `#2DD4BF`（青），都集中在常量文件里可改

## 技术说明

- 透视：分区用地面平面上的归一化矩形定义，渲染时做透视投影（远小近大），消失点即落日中心
- 音符位置由 `note.timeMs` 与当前时间差 + 下落速度换算成深度，再投影；`note` 字段确定落入哪个分区
- 全部霓虹色值为 TS 常量（Canvas 绘制），不进入 CSS token；纸墨主题仅保留给外壳/其他屏
