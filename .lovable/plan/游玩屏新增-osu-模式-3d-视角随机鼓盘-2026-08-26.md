# 游玩屏新增 osu! 模式（3D 视角随机鼓盘）

在游玩屏加一组模式切换按钮「舞台下落 / osu!」。osu! 模式沿用现在的舞台 3D 透视与封面背景，但不再有固定鼓阵和下落车道：每个音符在舞台平面上随机生成一个**带名称的鼓盘**，外圈缩圈收到判定圈时用 MIDI/键盘敲对应鼓件命中。

## 玩法规则

- **音符 = 一个鼓盘**：鼓盘用该鼓件的调色板色（与 `laneLayouts.ts` 一致）、椭圆透视形（踏板仍为方形斜放），盘面中央印鼓件中文名 + 键位字母，保证知道敲哪个。
- **缩圈**：出现时外圈半径约鼓盘 2.6 倍，随时间线性收缩，收到盘缘那一刻即判定时刻；提前量随速度档（0.5x–2x）变化。
- **判定**：必须敲对应鼓件，沿用现有 Perfect ±50ms / Good ±120ms / 超时 Miss、连击、分数、结算，与舞台模式共用逻辑。
- **随机落点**：在舞台可用区域（上 0.22 ~ 下 0.9 屏高之间）随机，按音符 index 做**确定性伪随机**（同一谱面每次一致，便于练习）；避让规则：与仍存活的鼓盘保持最小间距，落点带轻微「远小近大」透视缩放。
- **连打串**：时间间隔小于约半拍的连续音符归为一串，落点在同一区域内小步偏移排列，圆盘之间画渐隐连线并按顺序编号，形成 osu 式路径。
- **命中反馈**：盘面爆闪 + 放大回弹 + 火花粒子（复用现有粒子），Miss 则灰化下沉淡出。
- **HUD**：左上分数/连击、顶部进度条、判定文字、倒计时 4-3-2-1 全部沿用现有 HUD。
- **分区**：5 分区只出现 5 件对应的鼓盘，9 分区全部；谱面来源仍是谱面屏编好的 chart，不改编谱逻辑。

## 界面

游玩屏控制条最左侧新增一组按钮：`模式：舞台下落 | osu!`，与速度、分区并排；选择存进 `taiko.settings.v2`（新增 `playMode` 字段，默认舞台下落）。

## 技术说明

- **新增** `src/taiko/osuRenderer.ts`：背景（复用封面铺满 + 压灰）、鼓盘透视绘制（可从 stageRenderer 抽出的圆柱/方块画法简化版）、缩圈、名称文字、连线、命中/Miss 动画与粒子、HUD。
- **新增** `src/taiko/osuLayout.ts`：由 chart.notes 预计算每个音符的落点（确定性随机 + 间距避让）与连打串分组，纯函数、可测。
- **修改** `src/taiko/FallScreen.tsx`：渲染循环按 `playMode` 调用 `renderStage` 或 `renderOsu`；判定/Miss/倒计时/键盘与 MIDI 逻辑保持单一实现不复制。
- **修改** `src/taiko/songStore.tsx`（或设置持久化处）：加 `playMode: "stage" | "osu"`。
- **修改** `src/taiko/TaikoShell.tsx`：透传 playMode 与 setter。
- `laneLayouts.ts` 只增加「鼓件短名用于盘面文字」这一份表，摆位与色板不动。
- 全部 Canvas 2D，无新依赖。
